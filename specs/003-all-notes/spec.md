# 기능 명세: 학습노트 전체 목록

**기능 브랜치**: `feature/all-notes`

**작성일**: 2026-08-06

**상태**: 초안

**입력**: 사용자 설명: "`docs/specs/All-notes.md`의 내 학습노트 전체 목록과 모든 작성자의 공개 요약본 소속 학습노트 전체 목록을 Figma 디자인 및 확정된 사용자 결정에 맞춰 명세화"

> 사용자 결정 (2026-08-14): 모든 작성자의 공개 요약본 소속 학습노트 목록은 `/allnote`에서 제공한다. 기존 요약본별 목록 경로인 `/summary/[summaryId]/notes`는 사용하지 않으며, 해당 경로의 `new`, `[noteId]`, `[noteId]/edit` 하위 경로는 노트 생성·상세·수정 용도로 유지한다. 잠긴 요약본의 노트는 `/allnote`에 노출하지 않는다.

## 사용자 시나리오 및 테스트 _(필수)_

### 사용자 스토리 1 - 내 학습노트 전체 목록 확인 (우선순위: P1)

로그인한 사용자는 마이페이지에서 자신이 작성한 학습노트를 최신순으로 확인하고 원하는 노트의 상세 화면으로 이동한다.

**우선순위 이유**: 사용자가 자신의 학습 기록을 다시 찾고 이어서 학습하기 위한 핵심 흐름이다.

**독립 검증**: 로그인 사용자의 학습노트 데이터를 준비한 뒤 `/mypage/summaries`에 접근하여 총 개수, 정렬, 행별 정보, 추가 로딩 및 상세 이동을 검증할 수 있다.

**인수 시나리오**:

1. **상황** 로그인한 사용자가 작성한 학습노트가 있고, **동작** 사용자가 `/mypage/summaries`를 열면, **결과** 전체 개수와 최신 작성순 학습노트 첫 12개가 표시된다.
2. **상황** 첫 12개보다 많은 학습노트가 있고, **동작** 사용자가 목록 끝에 도달하면, **결과** 다음 12개가 중복 없이 추가된다.
3. **상황** 학습노트 행이 표시되어 있고, **동작** 사용자가 행을 선택하면, **결과** 행이 가진 `summaryId`와 `noteId`에 해당하는 학습노트 상세로 이동한다.
4. **상황** 비로그인 사용자가 `/mypage/summaries`에 접근하고, **동작** 접근 제한 모달이 표시되면, **결과** 사용자가 모달을 닫을 수 있으며 접근 시점부터 3초 후 `/login`으로 이동한다.

---

### 사용자 스토리 2 - 모든 학습노트 전체 목록 확인 (우선순위: P1)

방문자는 모든 작성자가 공개 요약본에 작성한 학습노트를 최신순으로 확인하고 상세 화면으로 이동한다.

**우선순위 이유**: 하나의 요약 주제에 연결된 다양한 학습 기록을 탐색하는 것이 전체 목록의 주요 가치다.

**독립 검증**: 여러 공개 요약본에 연결된 학습노트를 준비한 뒤 로그인 여부와 관계없이 `/allnote`에서 목록 표시, 추가 로딩 및 상세 이동을 검증할 수 있다.

**인수 시나리오**:

1. **상황** 여러 공개 요약본에 학습노트가 있고, **동작** 방문자가 `/allnote`를 열면, **결과** 모든 작성자의 학습노트가 최신 작성순으로 표시된다.
2. **상황** 방문자가 로그인하지 않았고, **동작** `/allnote`에 접근하면, **결과** 로그인 요구 없이 공개 요약본에 속한 목록을 조회할 수 있다.
3. **상황** 요약본이 비밀번호로 잠겨 있고, **동작** 방문자가 `/allnote`에 접근하면, **결과** 해당 요약본의 학습노트가 목록에 노출되지 않는다.
4. **상황** 목록 행이 표시되어 있고, **동작** 방문자가 행을 선택하면, **결과** 행의 `summaryId`와 `noteId`에 해당하는 학습노트 상세로 이동한다.

---

### 사용자 스토리 3 - 목록 상태와 배너 이용 (우선순위: P2)

사용자는 각 학습노트의 퀴즈 풀이 여부, 작성자, 제목과 작성일을 한눈에 구분하고, 제공된 광고 배너를 통해 연결된 목적지로 이동한다.

**우선순위 이유**: 상태 구분은 원하는 학습 기록을 찾는 데 도움을 주며 배너는 운영 콘텐츠의 연결 지점을 제공한다.

**독립 검증**: 퀴즈 풀이 전·후 항목, 배너 데이터, 빈 목록 및 실패 응답을 각각 준비해 시각적 상태와 후속 동작을 검증할 수 있다.

**인수 시나리오**:

1. **상황** 퀴즈를 풀지 않은 학습노트가 있고, **동작** 목록을 확인하면, **결과** 해당 행의 상태 영역에 회색 상태 이미지가 표시된다.
2. **상황** 퀴즈를 푼 학습노트가 있고, **동작** 목록을 확인하면, **결과** 해당 행의 상태 영역에 컬러 상태 이미지가 표시된다.
3. **상황** 배너 이미지와 목적지 URL이 제공되고, **동작** 사용자가 배너를 선택하면, **결과** 별도 CTA 버튼 없이 제공된 목적지로 이동한다.
4. **상황** 조회된 학습노트가 0개이고, **동작** 목록 화면이 표시되면, **결과** `학습 노트 리스트가 아직 생성되지 않았습니다.`라는 안내만 표시된다.

### 예외 상황

- 목록을 추가로 불러오는 동안 사용자가 다시 목록 끝에 도달해도 같은 묶음을 중복 요청하거나 중복 표시하지 않는다.
- 마지막 묶음이 12개 미만이거나 더 가져올 데이터가 없으면 추가 로딩을 종료하고 이미 표시한 목록을 유지한다.
- 일반 목록 조회가 실패하면 공통 오류 모달을 표시하고, 모달 종료 후 `/mypage/summaries`에서는 `/mypage`로, `/allnote`에서는 `/`로 이동한다.
- 존재하지 않는 `summaryId`로 접근하면 공통 오류 모달을 표시하고 3초 후 메인 페이지(`/`)로 자동 이동한다.
- 배너 이미지 또는 목적지 URL 중 하나라도 없으면 이동 가능한 배너로 취급하지 않는다.
- 긴 작성자명이나 제목은 데스크톱 목록의 열 경계를 침범하지 않아야 하며 전체 행 구조를 깨뜨리지 않아야 한다.

## 요구사항 _(필수)_

### 기능 요구사항

- **FR-001**: 시스템은 `/mypage/summaries`에서 로그인한 사용자가 작성한 학습노트 전체 목록을 제공해야 한다.
- **FR-002**: 시스템은 `/allnote`에서 모든 작성자의 공개 요약본 소속 학습노트 전체 목록을 로그인 여부와 관계없이 제공해야 한다.
- **FR-003**: 비로그인 사용자가 `/mypage/summaries`에 접근하면 고정 문구를 요구하지 않는 공통 접근 제한 모달을 표시해야 한다.
- **FR-004**: 접근 제한 모달은 사용자가 직접 닫을 수 있어야 하며, 닫기 여부와 관계없이 접근 시점부터 3초 후 `/login`으로 이동해야 한다.
- **FR-005**: 비밀번호로 잠긴 요약본의 학습노트는 `/allnote`의 전체 목록에 표시하지 않아야 한다.
- **FR-006**: `/allnote`는 특정 요약본 비밀번호 인증을 요구하지 않으며, 잠금 접근 제어는 요약본 상세 및 해당 기능의 기존 인증 계약을 따른다.
- **FR-007**: 두 목록은 학습노트를 작성일 기준 최신순으로 표시해야 한다.
- **FR-008**: 두 목록은 처음에 최대 12개를 표시하고 사용자가 목록 끝에 도달할 때마다 다음 항목을 최대 12개씩 추가해야 한다.
- **FR-009**: 시스템은 추가 로딩 중 중복 실행을 방지하고, 이미 표시한 항목을 중복해서 추가하지 않아야 한다.
- **FR-010**: 더 가져올 항목이 없으면 추가 로딩을 종료해야 한다.
- **FR-011**: 목록 상단은 `총 {count}개의 학습노트` 형식으로 전체 학습노트 수를 표시해야 한다.
- **FR-012**: 각 학습노트 행은 퀴즈 풀이 여부, 작성자 닉네임, 제목 및 작성일을 표시해야 한다.
- **FR-013**: 퀴즈 풀이 전 상태는 디자인에 정의된 회색 이미지로, 퀴즈 풀이 후 상태는 디자인에 정의된 컬러 이미지로 구분해야 한다.
- **FR-014**: 작성일은 `YYYY.MM.DD` 형식으로 표시하고 퀴즈 진행률 백분율은 작성일 영역에 표시하지 않아야 한다.
- **FR-015**: 각 목록 항목은 소속 요약본 식별자와 학습노트 식별자를 제공해야 한다.
- **FR-016**: 사용자가 목록 항목을 선택하면 `/summary/[summaryId]/notes/[noteId]`로 이동해야 한다.
- **FR-017**: 학습노트가 없으면 `학습 노트 리스트가 아직 생성되지 않았습니다.` 문구만 표시하고 별도 CTA를 제공하지 않아야 한다.
- **FR-018**: 시스템은 배너 이미지와 목적지 URL을 한 쌍으로 제공하고 목록 상단에 광고 배너를 표시해야 한다.
- **FR-019**: 사용자가 이동 가능한 배너를 선택하면 해당 배너 데이터가 지정한 목적지로 이동해야 하며 별도 CTA 버튼은 표시하지 않아야 한다.
- **FR-020**: 일반 목록 조회 실패 시 공통 오류 모달을 표시해야 한다.
- **FR-021**: 일반 목록 조회 실패 모달이 종료되면 `/mypage/summaries`에서는 `/mypage`로, `/allnote`에서는 `/`로 이동해야 한다.
- **FR-022**: 존재하지 않는 `summaryId`로 접근하면 공통 오류 모달을 표시하고 3초 후 `/`로 자동 이동해야 한다.
- **FR-023**: 화면 배치, 크기, 색상, 타이포그래피와 퀴즈 상태 이미지는 제공된 데스크톱 Figma 프레임을 기준으로 해야 한다.
- **FR-024**: 공통 Header는 별도 Header 명세를 따라야 하며 이 두 경로에서는 그 명세의 기본값인 펼친 상태로 시작해야 한다.
- **FR-025**: 태블릿 및 모바일 반응형 동작은 이 기능 범위에 포함하지 않아야 한다.
- **FR-026**: 북마크 목록 및 북마크 변경 동작은 이 기능 범위에 포함하지 않아야 한다.

### 핵심 엔티티 _(데이터를 다루는 경우에만 작성)_

- **학습노트**: 학습노트 식별자, 소속 요약본 식별자, 작성자 닉네임, 제목, 작성일 및 퀴즈 풀이 여부를 가진 목록 항목이다.
- **요약본**: 학습노트가 연결되는 주제 콘텐츠로, 식별자, 공개 여부, 잠금 여부 및 현재 세션의 비밀번호 인증 여부를 가진다.
- **목록 조회 결과**: 전체 개수, 현재 묶음의 학습노트, 다음 묶음 존재 여부를 포함하며 12개 단위의 연속 목록 표시를 지원한다.
- **광고 배너**: 화면에 표시할 이미지와 사용자가 선택했을 때 이동할 목적지 URL의 쌍이다.

## 성공 기준 _(필수)_

### 측정 가능한 결과

- **SC-001**: 사용자는 목록 진입 후 3초 이내에 전체 개수와 첫 학습노트 묶음 또는 빈 목록 안내를 확인할 수 있다.
- **SC-002**: 데이터가 있는 두 경로 모두에서 표시된 학습노트의 100%가 작성일 기준 최신순이며 각 행에 상태, 작성자, 제목 및 작성일이 표시된다.
- **SC-003**: 12개를 초과하는 목록에서 사용자가 목록 끝에 도달할 때마다 다음 묶음이 추가되고 중복 항목은 0개다.
- **SC-004**: 사용자는 표시된 학습노트 항목을 한 번 선택하여 정확한 소속 요약본의 학습노트 상세에 도달할 수 있다.
- **SC-005**: 비로그인 사용자의 `/mypage/summaries` 접근 시 100% 접근 제한 모달이 표시되고 모달을 닫아도 접근 시점부터 3초 후 로그인 페이지에 도달한다.
- **SC-006**: `/allnote`에서 잠긴 요약본에 소속된 보호 학습노트의 노출이 0건이다.
- **SC-007**: 퀴즈 풀이 전·후 테스트 항목의 상태 이미지가 각각 회색과 컬러로 100% 구분된다.
- **SC-008**: 빈 목록, 일반 조회 실패 및 존재하지 않는 요약본 시나리오가 각각 정의된 안내와 이동 결과로 처리된다.
- **SC-009**: 배너 데이터가 유효한 경우 사용자는 배너를 한 번 선택하여 데이터가 지정한 목적지에 도달할 수 있다.

## 가정

- 로그인 상태와 사용자 식별은 기존 서비스 영역에서 제공되며, `/allnote`의 공개 목록은 현재 로그인 여부와 무관하게 조회된다.
- 요약본 잠금 정보는 전체 목록의 필터 조건으로 사용하며 잠금 요약본 노트의 별도 비밀번호 인증은 `/allnote` 범위에 포함하지 않는다.
- 접근 제한·비밀번호·오류 모달의 시각적 구성과 접근 제한 안내 문구는 각각의 공통 UI 계약을 따르며 이 기능은 고정 문구를 새로 정의하지 않는다.
- 일반 조회 실패 후 이동은 공통 오류 모달의 허용된 종료 동작이 완료된 시점에 실행된다.
- 배너 목적지는 서버 데이터에 따라 내부 또는 외부 URL이 될 수 있으며, 이미지와 목적지 URL이 함께 유효할 때만 이동 가능한 배너로 표시된다.
- 학습노트 상세 경로와 Header 동작은 각각 기존 요약 상세 명세와 공통 Header 명세를 따른다.
