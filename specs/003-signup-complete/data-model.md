# 데이터 모델: 회원가입 완료 페이지

## 개요

이 기능은 정적 완료 안내 화면으로서 저장·조회할 도메인 엔터티가 없다. 아래 모델은 구현 중 화면 콘텐츠와 이동 계약이 변형되지 않도록 정리한 표시 모델이며 런타임 객체나 상태로 만들지 않는다.

## 완료 안내 표시 모델

| 필드               | 값                                        | 규칙                                             |
| ------------------ | ----------------------------------------- | ------------------------------------------------ |
| `title`            | `프다에 오신 걸 환영해요!`                | 한 번만 제목으로 표시한다.                       |
| `imageSrc`         | `/images/fbee.webp`                       | 기존 public 자산을 사용한다.                     |
| `imageDescription` | 프다 마스코트 프비를 설명하는 대체 텍스트 | 의미를 잃지 않는 짧은 문구를 제공한다.           |
| `messageLine1`     | `회원가입이 완료되었어요.`                | 첫 번째 안내 줄이다.                             |
| `messageLine2`     | `지금부터 나만의 학습을 시작해 보세요.`   | 두 번째 안내 줄이다.                             |
| `loginLabel`       | `로그인 하러 가기`                        | 이동 영역의 접근 가능한 이름과 화면 문구가 같다. |
| `loginHref`        | `/login`                                  | 정적 내부 경로이며 현재 탭에서 이동한다.         |

## 관계

- 완료 안내 표시 모델은 사용자, 회원가입 요청, 세션과 관계를 맺지 않는다.
- Header 상태는 이 페이지 모델에 포함하지 않고 공통 Header와 사이트 레이아웃의 계약에 의존한다.

## 검증 규칙

- 모든 문구는 명세의 확정 문구와 정확히 일치해야 한다.
- 이미지 경로를 다른 자산이나 새 자산으로 대체하지 않는다.
- 로그인 목적지는 `/login`만 허용한다.
- 마스코트는 어떤 화면에서도 원본 종횡비를 유지한다.
- 화면 표시 여부를 제어하는 상태나 전이 규칙은 없다.

## 상태 전이

페이지 내부 상태 전이는 없다. 사용자가 로그인 이동 영역을 선택하면 Next.js 내부 이동으로 `/login`에 진입하는 것만 정의한다.
