# 빠른 검증 안내: 회원가입 완료 페이지

## 사전 조건

- 프로젝트 의존성이 설치되어 있어야 한다.
- `public/images/fbee.webp`가 존재해야 한다.
- `/login` 페이지가 접근 가능해야 한다.

## 실행

```powershell
npm run dev
```

브라우저에서 `http://localhost:3000/signup/complete`에 접속한다.

## 기능 검증

1. 제목이 `프다에 오신 걸 환영해요!`로 표시되는지 확인한다.
2. 프비 이미지 뒤에 중심에서 바깥으로 흐려지는 원형 배경이 표시되는지 확인한다.
3. 이미지가 잘리거나 찌그러지지 않는지 확인한다.
4. 완료 안내가 지정된 두 줄로 표시되는지 확인한다.
5. `로그인 하러 가기`를 선택하면 현재 탭에서 `/login`으로 이동하는지 확인한다.
6. 페이지 내부에 Header가 중복 표시되지 않는지 확인한다.
7. 프비 이미지만 `0`에서 `-18px` 사이를 약 2.8초 동안 천천히 왕복하고 원형 배경·문구·Link는 고정되는지 확인한다.
8. 모션 감소 환경에서는 프비 이미지가 움직이지 않는지 확인한다.
9. 모달, 로딩, 자동 이동과 승인되지 않은 추가 애니메이션이 실행되지 않는지 확인한다.

세부 화면 계약은 [contracts/SignupCompletePage.md](./contracts/SignupCompletePage.md)를 따른다.

## 반응형 검증

개발자 도구에서 각각 1320px, 1024px, 480px 너비로 확인한다.

- 콘텐츠가 화면의 중앙 영역에 배치되는가?
- 제목, 이미지, 안내와 로그인 이동 영역의 순서가 유지되는가?
- 480px에서 좌우 여백이 유지되고 가로 스크롤이 생기지 않는가?
- 기준 화면 사이 너비에서도 콘텐츠가 겹치거나 잘리지 않는가?
- 이미지 비율과 원형 그라디언트의 중심이 유지되는가?

## 키보드 검증

1. `Tab` 키로 `로그인 하러 가기`에 이동한다.
2. 포커스 표시가 눈에 보이는지 확인한다.
3. `Enter` 키로 `/login` 이동이 가능한지 확인한다.
