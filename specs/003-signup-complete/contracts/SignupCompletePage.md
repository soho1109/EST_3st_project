# 화면 계약: SignupCompletePage

## 경로와 소유권

- 공개 경로: `/signup/complete`
- 페이지 소유 파일: `src/app/(site)/signup/complete/page.js`
- 스타일 소유 파일: `src/app/(site)/signup/complete/page.module.scss`
- Header 소유권: `src/app/(site)/layout.js` 및 공통 Header 기능

## 입력 계약

이 페이지는 props, URL 파라미터, 쿼리 문자열 또는 API 응답을 입력으로 받지 않는다. Supabase 세션과 현재 탭 `sessionStorage`의 회원가입 완료 시각을 확인한다.

- 로그인 사용자는 `alreadyLoggedIn` 모드로 안내한 뒤 메인으로 이동한다.
- 유효한 완료 시각이 없는 비로그인 사용자는 `error` 모드와 상태 `403`으로 `접근 권한이 없습니다.`를 안내한 뒤 `/signup`으로 이동한다.

## 출력 계약

페이지는 다음 항목을 순서대로 한 번씩 제공한다.

1. `프다에 오신 걸 환영해요!` 제목
2. `fbee.webp`와 CSS 원형 그라디언트
3. `회원가입이 완료되었어요.` 안내
4. `지금부터 나만의 학습을 시작해 보세요.` 안내
5. `/login`으로 이동하는 `로그인 하러 가기` Link

## 반응형 계약

| 화면      | 필수 결과                                                                        |
| --------- | -------------------------------------------------------------------------------- |
| 1320px    | 데스크톱 Figma의 중앙 배치, 큰 제목·마스코트·로그인 이동 영역을 표시한다.        |
| 1024px    | 태블릿 Figma의 크기와 간격으로 조절하되 중앙 배치를 유지한다.                    |

| 중간 너비 | 콘텐츠가 잘리거나 겹치지 않고 이미지 비율이 유지된다.                            |

## 상호작용 계약

- 사용 가능한 유일한 페이지 상호작용은 로그인 Link다.
- 마우스 선택과 키보드 활성화 모두 `/login`으로 이동해야 한다.
- 새 탭을 열거나 자동으로 이동하지 않는다.
- 마스코트와 배경은 선택 가능한 컨트롤이 아니다.
- 프비 이미지만 `transform`으로 `0`에서 `-18px` 사이를 약 2.8초 동안 천천히 무한 왕복한다.
- 원형 그라디언트, 제목, 안내 문구와 로그인 Link는 움직이지 않는다.
- 모션 감소 환경에서는 프비 애니메이션을 중지하고 기본 위치로 표시한다.

## 접근성 계약

- 페이지에는 내용을 대표하는 하나의 `h1`이 있어야 한다.
- 마스코트에는 의미 있는 `alt`를 제공한다.
- 로그인 이동 영역은 Link의 문구만으로 목적을 이해할 수 있어야 한다.
- 키보드 포커스가 시각적으로 식별되어야 한다.
- 색상만으로 이동 가능 여부를 전달하지 않는다.

## 제외 계약

- Header 직접 렌더링 또는 수정
- Supabase API를 통한 회원가입 완료 여부 재조회
- 이메일, 비밀번호 또는 사용자 ID의 브라우저 저장
- Loading, Suspense와 `loading.js`
- 새로운 모달 구현; 로그인 사용자 접근은 기존 CommonModal의 `alreadyLoggedIn` 모드를 재사용한다.
- 승인된 프비 상하 이동 외의 애니메이션, 타이머, 자동 이동과 새로고침
- 새 패키지, 상태 관리 도구와 공통 컴포넌트
