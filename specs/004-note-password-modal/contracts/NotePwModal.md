# UI 계약: NotePwModal

## 목적

잠긴 요약 노트의 비밀번호를 입력받아 호출 측 검증 함수에 전달하는 공통 UI 컴포넌트 계약이다.

## 컴포넌트 위치

```text
src/components/NotePwModal.jsx
src/components/NotePwModal.module.scss
```

## Props

| 이름 | 형태 | 필수 | 기본값 | 책임 |
|---|---|---:|---|---|
| `isOpen` | Boolean | 예 | 없음 | 모달과 배경막의 표시 여부를 제어한다. |
| `isSubmitting` | Boolean | 아니오 | `false` | 검증 중 입력과 제출을 비활성화한다. |
| `errorMessage` | 문자열 | 아니오 | `""` | 비밀번호 불일치 문구를 모달 내부에 표시한다. |
| `onSubmit` | 함수 | 예 | 없음 | 공백을 제외한 비밀번호 문자열을 인자로 받아 호출 측 검증을 시작한다. |
| `onClose` | 함수 | 예 | 없음 | 사용자가 닫기 버튼을 눌렀음을 호출 측에 알린다. |

## 이벤트 계약

### 제출

```text
onSubmit(password)
```

- `입력 완료` 버튼 또는 Enter 키로 실행한다.
- `password`가 비어 있거나 공백뿐이면 호출하지 않는다.
- `isSubmitting`이 참이면 호출하지 않는다.
- 유효한 `password`를 전달한 직후 내부 입력값을 초기화한다.
- 컴포넌트는 검증 결과, 세션 저장, 경로 이동을 직접 처리하지 않는다.

### 닫기

```text
onClose()
```

- 우측 상단 Material `close` 버튼으로만 실행한다.
- 실행 전에 컴포넌트의 입력값을 초기화한다.
- 배경막 클릭으로는 실행하지 않는다.

## 렌더링 계약

- `isOpen`이 거짓이면 아무 UI도 렌더링하지 않는다.
- `isOpen`이 참이면 전체 화면 배경막과 중앙 모달을 렌더링한다.
- 제목은 `게시글 비밀번호 입력`이다.
- 입력 레이블과 placeholder는 `비밀번호 입력`이다.
- 제출 버튼 문구는 `입력 완료`이다.
- `errorMessage`가 있으면 입력 영역과 연결된 인라인 오류로 표시한다. 입력값은 제출 직후 이미 초기화된 상태다.
- `isSubmitting` 중에는 비밀번호 입력과 제출 버튼을 비활성화한다.

## 호출 측 계약

- 호출 측은 비밀번호 검증을 수행하고 `isSubmitting`을 갱신한다.
- 불일치 시 `비밀번호가 일치하지 않습니다.`를 `errorMessage`로 전달한다.
- 성공 시 `isOpen`을 거짓으로 전환하고 요청한 보호 경로로 이동한다.
- 시스템 오류 시 `isOpen`을 거짓으로 전환하고 원래 페이지에서 `CommonModal`을 표시한다.
- 동일 요약 노트의 세션 인증 유지 여부는 호출 측 또는 별도 인증 계층이 관리한다.

## 접근성 계약

- 모달은 대화상자임을 보조 기술에 전달한다.
- 모달 제목을 대화상자 이름으로 연결한다.
- 비밀번호 입력은 명시적인 레이블을 가진다.
- 오류 문구는 입력과 연결하고 갱신 사실을 전달할 수 있어야 한다.
- 닫기 버튼은 아이콘 외에 접근 가능한 이름 `닫기`를 제공한다.
- 장식용 Material 아이콘은 보조 기술에서 제외한다.
