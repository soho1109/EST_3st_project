# 빠른 검증 안내: 요약 노트 비밀번호 모달

## 목적

`NotePwModal` 구현 후 명세와 UI 계약을 충족하는지 백엔드 연결 없이 검증한다.

## 사전 조건

- Node.js와 프로젝트 의존성이 설치되어 있다.
- `src/components/NotePwModal.jsx`와 `NotePwModal.module.scss`가 구현되어 있다.
- `src/app/(dev)/dev/notepwmodal/page.js`에 백엔드 없는 전용 확인 화면이 준비되어 있다.
- Material Symbols 스타일이 루트 레이아웃에서 정상적으로 제공된다.

## 실행

```powershell
npm run dev
```

브라우저에서 `http://localhost:3000/dev/notepwmodal`에 접속한다.

기존 `src/app/(dev)/dev/page.js`는 이 검증을 위해 수정하지 않는다.

## 검증 시나리오

### 1. 기본 디자인과 배경 차단

1. `isOpen=true`로 모달을 표시한다.
2. 제목, 레이블, 비밀번호 입력, 닫기 아이콘, `입력 완료` 버튼을 확인한다.
3. 뒤쪽 페이지 요소를 클릭한다.

**기대 결과**: 디자인 요소가 중앙 모달에 표시되고 뒤쪽 페이지의 클릭 동작은 발생하지 않는다. 배경막을 클릭해도 모달은 유지된다.

### 2. 버튼 제출

1. 비밀번호를 입력한다.
2. `입력 완료`를 누른다.

**기대 결과**: `onSubmit`이 입력값으로 한 번 호출된다.

### 3. Enter 제출

1. 비밀번호 입력에 포커스를 둔다.
2. 값을 입력하고 Enter 키를 누른다.

**기대 결과**: 버튼 제출과 동일하게 `onSubmit`이 한 번 호출되며 페이지가 새로고침되지 않는다.

### 4. 빈 값 제출 방지

빈 문자열과 공백만 입력한 값으로 버튼 및 Enter 제출을 각각 시도한다.

**기대 결과**: `onSubmit`이 호출되지 않는다.

### 5. 검증 중 중복 제출 방지

1. `isSubmitting=true`로 전환한다.
2. 입력 변경, 버튼 클릭, Enter 제출을 시도한다.

**기대 결과**: 입력과 버튼이 비활성화되고 추가 `onSubmit` 호출이 없다.

### 6. 비밀번호 불일치

1. 비밀번호를 입력한다.
2. 제출 후 `errorMessage="비밀번호가 일치하지 않습니다."`를 전달한다.

**기대 결과**: 제출 직후 입력값이 비워지고, 모달은 열린 상태를 유지하며 오류 문구가 표시된다. 같은 오류가 반복되어도 새 값을 입력해 재제출할 수 있다.

### 7. 닫기

1. 비밀번호를 입력한다.
2. 우측 상단 닫기 버튼을 누른다.

**기대 결과**: 입력값이 초기화되고 `onClose`가 한 번 호출된다. 호출 측이 모달을 닫아도 현재 경로는 유지된다.

### 8. 시스템 오류 연결

호출 측의 검증 실패 상태를 시스템 오류로 전환한다.

**기대 결과**: 호출 측이 비밀번호 모달을 닫고 원래 페이지에서 `CommonModal`을 표시한다. 현재 코드에 `CommonModal`이 없다면 이 항목은 해당 컴포넌트가 준비된 뒤 통합 검증한다.

## 정적 검증

```powershell
npm run lint
npm run build
```

**기대 결과**: 새 오류 없이 두 명령이 완료된다.
