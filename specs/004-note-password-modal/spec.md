# 기능 명세: 요약 노트 비밀번호 모달

**기능 브랜치**: `feature/note-password-modal`

**작성일**: 2026-08-06

**상태**: 초안

**입력**: 사용자 설명: 잠긴 요약 노트에 진입하기 전에 비밀번호를 확인하는 공통 `NotePwModal.jsx`의 기능과 디자인을 명세한다.

## 명세 및 디자인 참조

- 전체 요약 노트 명세: [`../003-all-summary/spec.md`](../003-all-summary/spec.md)
- 전체 학습 노트 명세: [`../003-all-notes/spec.md`](../003-all-notes/spec.md)
- 요약 노트 상세 명세: [`../002-summary-detail/spec.md`](../002-summary-detail/spec.md)
- 디자인: 제공된 Figma 파일의 `Frame 2778` 및 하위 요소(노드 `328:4540`)
- 보조 디자인 자료: 사용자가 제공한 전체 화면 및 모달 확대 스크린샷

## 범위

이 기능은 잠긴 요약 노트 진입을 위한 공통 비밀번호 모달의 표시, 닫기, 입력, 검증 결과 처리까지 포함한다. 비밀번호 검증 API의 구체적인 통신 구조, 요약 노트 상세 페이지 자체의 구현, 공통 오류 모달의 내부 구현은 범위에서 제외한다.

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 잠긴 요약 노트 인증 (우선순위: P1)

사용자는 잠긴 요약 노트에 진입하기 위해 비밀번호를 입력하고 확인할 수 있다.

**우선순위 이유**: 잠긴 콘텐츠의 보호와 정상적인 상세 진입을 동시에 보장하는 모달의 핵심 목적이다.

**독립 검증**: 잠긴 요약 노트에서 모달을 열고 올바른 비밀번호를 버튼과 Enter 키로 각각 제출하여 모달 종료 및 목적지 이동을 확인한다.

**인수 시나리오**:

1. **상황** 잠긴 요약 노트 진입을 시도했을 때, **동작** 비밀번호 모달이 열리면, **결과** 배경이 회색으로 가려지고 배경 페이지를 클릭할 수 없다.
2. **상황** 비밀번호 모달에 올바른 비밀번호가 입력되었을 때, **동작** 사용자가 `입력 완료` 버튼을 누르면, **결과** 비밀번호가 확인되고 모달이 닫힌 뒤 요청한 요약 노트 경로로 이동한다.
3. **상황** 비밀번호 모달에 올바른 비밀번호가 입력되었을 때, **동작** 사용자가 Enter 키를 누르면, **결과** 버튼 제출과 동일하게 비밀번호가 확인되고 요청한 요약 노트 경로로 이동한다.
4. **상황** 같은 브라우저 세션에서 해당 요약 노트의 비밀번호 확인이 완료되었을 때, **동작** 사용자가 동일한 요약 노트의 보호된 경로에 다시 접근하면, **결과** 비밀번호를 다시 요구하지 않는다.

---

### 사용자 스토리 2 - 잘못된 비밀번호 재입력 (우선순위: P2)

사용자는 비밀번호가 틀렸다는 사실을 모달 안에서 확인하고 즉시 다시 입력할 수 있다.

**우선순위 이유**: 입력 실수로 접근 흐름이 중단되지 않도록 명확한 피드백과 재시도 수단이 필요하다.

**독립 검증**: 잘못된 비밀번호를 제출한 뒤 오류 문구, 입력값 초기화, 모달 유지 및 재제출 가능 여부를 확인한다.

**인수 시나리오**:

1. **상황** 잘못된 비밀번호가 입력되었을 때, **동작** 검증 결과가 반환되면, **결과** 모달 안에 `비밀번호가 일치하지 않습니다.`가 표시되고 입력값은 비워진다.
2. **상황** 비밀번호 오류가 표시된 상태에서, **동작** 사용자가 새 비밀번호를 입력하면, **결과** 모달을 닫지 않고 다시 제출할 수 있다.

---

### 사용자 스토리 3 - 모달 닫기 및 서버 오류 처리 (우선순위: P3)

사용자는 인증을 취소하고 원래 페이지에 머물 수 있으며, 서버 오류가 발생하면 공통 오류 안내를 받을 수 있다.

**우선순위 이유**: 사용자가 접근 시도를 안전하게 취소하고 인증 실패와 시스템 실패를 구분해 대응할 수 있어야 한다.

**독립 검증**: 닫기 아이콘 동작과 서버·네트워크 오류 상황을 각각 발생시켜 원래 페이지 유지 및 공통 오류 모달 표시를 확인한다.

**인수 시나리오**:

1. **상황** 비밀번호 모달이 열린 상태에서, **동작** 사용자가 우측 상단의 닫기 아이콘을 누르면, **결과** 비밀번호 모달만 닫히고 원래 페이지에 머문다.
2. **상황** 비밀번호 확인 중 서버 또는 네트워크 오류가 발생했을 때, **동작** 오류가 확인되면, **결과** 비밀번호 모달이 닫히고 원래 페이지 위에 공통 오류 모달이 표시된다.

### 예외 상황

- 비밀번호가 비어 있으면 검증 요청을 보내지 않는다.
- 검증 요청이 진행 중일 때 입력과 중복 제출을 허용하지 않는다.
- 모달 배경 영역의 클릭은 뒤쪽 페이지로 전달되지 않으며 모달을 닫지 않는다.
- 잘못된 비밀번호는 인증 실패로 처리하고, 서버 또는 네트워크 오류와 구분한다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 잠긴 요약 노트 진입 요청 시 현재 페이지 위에 비밀번호 모달을 표시해야 한다.
- **FR-002**: 모달이 열리면 회색 배경막이 화면의 나머지 영역을 덮고 뒤쪽 페이지의 포인터 상호작용을 차단해야 한다.
- **FR-003**: 모달은 디자인을 기준으로 흰색의 둥근 컨테이너, `게시글 비밀번호 입력` 제목, `비밀번호 입력` 레이블, 잠금 아이콘이 있는 입력란, 주황색 `입력 완료` 버튼을 표시해야 한다.
- **FR-004**: 모달 우측 상단에는 Material `close` 아이콘을 사용한 닫기 조작 요소가 있어야 한다.
- **FR-005**: 비밀번호 입력값은 화면에 그대로 노출되지 않아야 한다.
- **FR-006**: 사용자는 `입력 완료` 버튼 또는 Enter 키로 비밀번호를 제출할 수 있어야 한다.
- **FR-007**: 빈 비밀번호는 제출할 수 없어야 한다.
- **FR-008**: 검증이 진행되는 동안 입력과 제출을 비활성화하고 중복 요청을 방지해야 한다.
- **FR-009**: 올바른 비밀번호가 확인되면 모달을 닫고 호출 측이 요청한 해당 요약 노트의 보호된 경로로 이동해야 한다.
- **FR-010**: 올바른 비밀번호 확인 결과는 같은 브라우저 세션의 동일한 요약 노트 보호 경로에서 재사용되어야 한다.
- **FR-011**: 잘못된 비밀번호가 확인되면 모달 내부에 `비밀번호가 일치하지 않습니다.`를 표시해야 한다.
- **FR-012**: 잘못된 비밀번호가 확인되면 기존 입력값을 비우고 재입력을 허용해야 한다.
- **FR-013**: 사용자가 닫기 아이콘을 누르면 인증하지 않은 채 모달을 닫고 호출한 페이지를 유지해야 한다.
- **FR-014**: 배경막 클릭은 모달을 닫지 않아야 한다.
- **FR-015**: 서버 또는 네트워크 오류가 발생하면 비밀번호 모달을 닫고 호출한 페이지에서 기존 `CommonModal`을 이용한 공통 오류 안내를 표시해야 한다.
- **FR-016**: 이 공통 컴포넌트의 파일명과 컴포넌트명은 `NotePwModal.jsx`와 `NotePwModal`이어야 한다.

### 핵심 엔티티 *(데이터를 다루는 경우에만 작성)*

- **비밀번호 인증 요청**: 대상 요약 노트 식별자와 사용자가 입력한 비밀번호를 포함하며 잠금 콘텐츠 접근 가능 여부를 확인한다.
- **요약 노트 인증 상태**: 같은 브라우저 세션에서 특정 요약 노트의 비밀번호 확인이 완료되었는지를 나타낸다.
- **호출 문맥**: 모달을 연 페이지와 인증 성공 후 이동할 보호 경로를 나타낸다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 사용자는 올바른 비밀번호를 한 번 제출하여 요청한 잠긴 요약 노트 경로에 도달할 수 있다.
- **SC-002**: 버튼 클릭과 Enter 키 제출은 동일한 검증 결과와 후속 동작을 제공한다.
- **SC-003**: 잘못된 비밀번호가 반환된 모든 경우에 오류 문구가 표시되고 입력값이 비워져 즉시 재시도할 수 있다.
- **SC-004**: 모달이 열린 동안 뒤쪽 페이지로 전달되는 포인터 상호작용은 0건이어야 한다.
- **SC-005**: 연속 제출을 시도해도 한 번의 검증이 완료되기 전까지 추가 검증 요청은 발생하지 않는다.
- **SC-006**: 서버 또는 네트워크 오류가 반환된 모든 경우에 비밀번호 모달이 닫히고 원래 페이지에 공통 오류 모달이 표시된다.
- **SC-007**: 닫기 아이콘을 누르면 인증이나 경로 이동 없이 원래 페이지가 유지된다.

## 가정

- 잠긴 요약 노트의 식별자와 인증 성공 후 이동할 경로는 모달을 여는 기능에서 제공한다.
- 비밀번호 검증 수단과 같은 브라우저 세션의 인증 상태 저장 방식은 구현 계획에서 기존 인증·통신 구조에 맞춰 결정한다.
- 공통 오류 모달은 기존 `CommonModal`을 재사용하며 구체적인 문구와 후속 동작은 해당 공통 컴포넌트 계약을 따른다.
- 제공된 디자인은 데스크톱 화면을 기준으로 하며 모바일 및 태블릿 전용 배치는 이 명세 범위에서 제외한다.
