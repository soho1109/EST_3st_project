# 기능 명세: 마이페이지 대시보드

**기능 브랜치**: `feature/mypage-dashboard`

**작성일**: 2026-08-05

**상태**: 초안

**입력**: 사용자 설명: "`docs/specs/Mypage.md`의 전체 요구사항 및 연결된 Figma 마이페이지 기본·프로필 수정 프레임"

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 내 정보와 활동 확인 (우선순위: P1)

로그인한 사용자는 마이페이지에서 자신의 프로필, 학습 노트, 직접 작성한 요약 노트와 북마크한 요약 노트를 한 화면에서 확인한다.

**우선순위 이유**: 마이페이지의 핵심 목적은 사용자가 자신의 정보와 활동을 확인하는 것이다.

**독립 검증**: 로그인한 사용자의 각 데이터가 있을 때 프로필과 세 목록이 요구된 순서와 개수로 표시되는지 확인한다.

**인수 시나리오**:

1. **상황** 로그인한 사용자에게 프로필과 학습 노트가 있고, **동작** 사용자가 `/mypage`에 접속하면, **결과** 프로필과 학습 노트 표가 표시된다.
2. **상황** 로그인한 사용자가 직접 작성한 요약 노트를 5개 이상 보유하고, **동작** 마이페이지를 열면, **결과** 최신순 요약 노트는 최대 4개만 표시된다.
3. **상황** 로그인한 사용자가 북마크한 요약 노트를 보유하고, **동작** 마이페이지를 열면, **결과** 북마크 추가가 늦은 순서부터 최대 4개가 표시된다.
4. **상황** 각 목록에 표시할 항목이 없고, **동작** 사용자가 마이페이지를 열면, **결과** 해당 섹션의 빈 목록 안내 문구가 표시된다.

---

### 사용자 스토리 2 - 프로필 수정 (우선순위: P1)

로그인한 사용자는 페이지를 벗어나지 않고 프로필 사진, 닉네임과 한 줄 소개를 수정하고 변경 결과를 바로 확인한다.

**우선순위 이유**: 개인 정보 갱신은 마이페이지의 핵심 상호작용이다.

**독립 검증**: 사용자가 수정 상태에 들어가 사진·닉네임·소개를 바꾼 뒤 수정완료를 누르면 읽기 전용 화면에 변경값이 표시되는지 확인한다.

**인수 시나리오**:

1. **상황** 기본 프로필 화면이고, **동작** 사용자가 `프로필 수정`을 누르면, **결과** 닉네임과 소개는 입력 상태로, 버튼은 `수정완료` 상태로 전환된다.
2. **상황** 프로필 수정 상태이고, **동작** 사용자가 새 이미지를 선택하면, **결과** 저장 전까지 선택 이미지는 미리보기로만 표시된다.
3. **상황** 프로필 수정 상태이고, **동작** 사용자가 `수정완료`를 누른 뒤 저장에 성공하면, **결과** 페이지 이동 없이 읽기 전용 상태로 돌아가 변경값이 표시된다.
4. **상황** 프로필 사진이 등록되지 않았고, **동작** 사용자가 마이페이지를 열면, **결과** 기본 프로필 이미지가 표시된다.

---

### 사용자 스토리 3 - 요약 노트 목록으로 이동 (우선순위: P2)

로그인한 사용자는 내 요약 노트와 북마크 섹션의 더보기를 통해 각각의 전체 목록을 확인한다.

**우선순위 이유**: 대시보드에 표시하지 못하는 나머지 항목을 탐색할 수 있게 한다.

**독립 검증**: 각 더보기 링크를 눌러 지정된 전체 목록으로 이동하는지 확인한다.

**인수 시나리오**:

1. **상황** 마이페이지의 내 요약 노트 섹션이고, **동작** 사용자가 `더보기`를 누르면, **결과** `/mypage/summaries`로 이동한다.
2. **상황** 마이페이지의 북마크 섹션이고, **동작** 사용자가 `더보기`를 누르면, **결과** `/mypage/bookmarks`로 이동한다.

### 예외 상황

- 프로필 사진·학습 노트·요약 노트·북마크 데이터가 없을 때 각 섹션은 원본 명세의 빈 목록 안내 문구를 표시한다.
- 프로필 변경을 저장하지 못할 때 사용자는 실패 사실을 알 수 있고, 입력한 변경값은 재시도할 수 있도록 유지한다.
- 지원하지 않는 이미지 형식, 파일 크기 초과 및 이미지 저장 실패의 구체적인 제한값과 안내 방식은 별도 결정이 필요하다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 로그인한 사용자가 `/mypage`에서 본인의 프로필, 학습 노트 목록, 직접 작성한 요약 노트 및 북마크한 요약 노트를 확인할 수 있게 해야 한다.
- **FR-002**: 시스템은 프로필 사진, 닉네임과 한 줄 소개를 읽기 전용 상태로 표시하고, 등록된 사진이 없으면 기본 이미지를 표시해야 한다.
- **FR-003**: 시스템은 사용자가 `프로필 수정`을 선택하면 사진, 닉네임과 한 줄 소개를 편집할 수 있는 상태로 전환해야 하며, `수정완료` 선택 후 성공하면 현재 페이지에서 읽기 전용 상태로 돌아가야 한다.
- **FR-004**: 시스템은 사용자가 프로필 사진을 선택한 후 저장 전까지 선택한 사진의 미리보기를 표시하고, 저장 성공 시에만 프로필 정보에 반영해야 한다.
- **FR-005**: 시스템은 학습 노트를 표 형태로 표시하고, 각 항목에서 상태, 작성자, 학습 노트 제목, 연관 요약 노트 주제 및 작성일을 제공해야 한다.
- **FR-006**: 시스템은 사용자가 작성한 요약 노트를 작성일 최신순으로 최대 4개 표시하고, 각 카드에 작성자 프로필 이미지·닉네임, 제목, 내용 일부, 작성일 및 잠금 상태를 표시해야 한다.
- **FR-007**: 시스템은 사용자가 북마크한 요약 노트를 북마크 추가가 늦은 순서부터 최대 4개 표시하고, 각 카드에 작성자 프로필 이미지·닉네임, 제목, 내용 일부, 작성일, 북마크 상태 및 잠금 상태를 표시해야 한다.
- **FR-008**: 시스템은 데이터가 없는 경우 학습 노트에는 `현재 리스트가 없습니다.`, 내 요약 노트에는 `요약 노트가 아직 생성되지 않았습니다.`, 북마크에는 `북마크한 요약 노트가 없습니다.`를 표시해야 한다.
- **FR-009**: 시스템은 내 요약 노트 더보기를 `/mypage/summaries`로, 북마크 더보기를 `/mypage/bookmarks`로 연결해야 한다.
- **FR-010**: 시스템은 프로필 수정 상태에서 닉네임과 한 줄 소개 입력 영역, 사진 미리보기 및 `수정완료` 버튼을 표시해야 한다.
- **FR-011**: 시스템은 프로필 사진 위에 마우스를 올리면 사진 변경 가능 상태를 시각적으로 표시해야 한다.
- **FR-012**: 시스템은 마이페이지의 기본 화면과 프로필 수정 화면에 연결된 Figma 프레임의 데스크톱 배치, 색상, 타이포그래피 및 컴포넌트 상태를 반영해야 한다.
- **FR-013**: 시스템은 비로그인 사용자가 `/mypage`에 접근하면 `/login`으로 이동시켜야 한다.
- **FR-014**: 시스템은 마이페이지의 공통 사이드바를 펼친 상태로 시작해야 한다.
- **FR-015**: 시스템은 학습 노트 더보기를 `/allnote`로 연결하고, 학습 노트 항목·요약 노트 카드·북마크 카드를 각각의 상세 화면으로 연결해야 한다.

### 핵심 엔티티

- **프로필**: 사용자 사진, 닉네임, 한 줄 소개로 구성되며 사용자가 수정할 수 있다.
- **학습 노트**: 상태, 작성자, 제목, 연관 요약 노트 주제와 작성일을 가진 사용자 활동 항목이다.
- **요약 노트**: 작성자 정보, 제목, 내용 일부, 작성일과 잠금 상태를 가진 노트이며 작성자 또는 북마크 사용자와 연관된다.
- **북마크**: 사용자가 요약 노트를 저장한 기록이며 표시 순서와 북마크 상태를 결정한다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 로그인한 사용자는 마이페이지 진입 후 프로필과 세 활동 섹션의 표시 상태를 한 화면에서 확인할 수 있다.
- **SC-002**: 직접 작성한 요약 노트와 북마크 섹션은 각각 한 번에 4개 이하의 카드만 표시한다.
- **SC-003**: 사용자는 페이지 이동 없이 프로필 수정 시작부터 저장 성공 후 변경값 확인까지 완료할 수 있다.
- **SC-004**: 각 활동 섹션은 데이터가 없을 때 100%의 경우 지정된 빈 목록 안내 문구를 표시한다.
- **SC-005**: 사용자는 내 요약 노트와 북마크의 더보기 링크를 통해 각각 지정된 전체 목록으로 이동할 수 있다.

## 가정

- 이 기능은 로그인한 사용자의 마이페이지 경험을 대상으로 하며, 비로그인 사용자는 `/login`으로 이동한다.
- 이 기능은 원본 명세에 정의된 조회·수정·목록 표시 범위를 포함한다. 북마크 해제와 잠금 해제는 포함하지 않으며, 학습 노트 항목과 두 종류의 요약 노트 카드는 각각의 상세 화면으로 이동한다.
- 데이터 조회 실패의 상세 문구와 이미지 형식·용량·닉네임 길이 제한은 별도 정책이 정해진 뒤 구체화한다.
- 공통 Header와 Sidebar의 구현 또는 수정은 이 기능의 산출 범위에 포함하지 않는다.
