# 빠른 검증 안내: 공통 전체 화면 로딩

## 사전 조건

- 의존성 설치가 완료되어 있어야 한다.
- `public/images/clear.webp`가 존재해야 한다.
- 개발 확인 경로는 `/dev/loading`이다.

## 실행

```powershell
npm run dev
```

브라우저에서 `http://localhost:3000/dev/loading`을 연다.

## 검증 시나리오

### 기본 표시

1. 개발 확인 화면에서 Loading 표시 동작을 실행한다.
2. 연한 회색 배경막이 viewport 전체를 덮는지 확인한다.
3. 중앙에 프로필 이미지와 흰색 막대 12개가 표시되는지 확인한다.
4. `잠시만 기다려주세요.`와 `로딩중입니다`가 두 줄로 표시되는지 확인한다.
5. 막대 12개의 투명도가 차례대로 바뀌는지 확인한다.

### 상호작용 차단

1. Loading 뒤에 개발 확인용 버튼 또는 입력이 있는 상태로 Loading을 표시한다.
2. 포인터 클릭이 뒤쪽 컨트롤에 전달되지 않는지 확인한다.
3. Tab과 키보드 입력으로 뒤쪽 컨트롤이 실행되지 않는지 확인한다.
4. Loading을 제거한 뒤 해당 컨트롤을 다시 조작할 수 있는지 확인한다.

### 표시 상태와 중복 방지

1. 개발 확인 화면의 Boolean `isLoading`으로 표시와 제거를 반복한다.
2. 한 번의 표시에서 전체 화면 오버레이가 하나만 존재하는지 확인한다.
3. 같은 작업에 `isLoading`과 Suspense fallback을 동시에 사용하지 않았는지 확인한다.
4. 여러 Suspense 경계에 전체 화면 Loading을 중복 배치하지 않았는지 확인한다.

### 모션 감소

1. 운영체제 또는 브라우저에서 모션 감소 설정을 활성화한다.
2. 막대의 투명도 변화 주기가 현저히 길어지는지 확인한다.
3. 정적 이미지와 안내 문구만으로도 로딩 상태를 이해할 수 있는지 확인한다.

## 정적 검증

```powershell
npm run lint
```

Loading 관련 lint 오류 없이 완료되어야 한다. 전체 production build는 페이지 통합 또는 배포 전 검증에서 실행한다.
