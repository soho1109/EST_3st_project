# UI 계약: EmptyState

## 목적

`EmptyState`는 정상적으로 확인된 목록에 표시할 항목이 없을 때 공통 이미지와 문맥별 안내 문구를 제공한다. 목록 조회, 빈 상태 판정과 후속 행동은 호출 영역이 관리한다.

## 컴포넌트

```text
파일: src/components/EmptyState.jsx
이름: EmptyState
스타일: src/components/EmptyState.module.scss
이미지: public/images/clear.webp
```

## 입력 계약

| 입력      | 형식   | 필수 | 책임                                     |
| --------- | ------ | ---- | ---------------------------------------- |
| `message` | 문자열 | 예   | 목록 문맥에 맞는 안내 문구를 그대로 표시 |

- `items`, `isLoading`, `hasError`, `view`, `href`, action callback 또는 페이지별 스타일 입력은 받지 않는다.
- 호출자는 아래 문구 매핑 중 현재 목록에 해당하는 값을 전달한다.

| 적용 문맥          | 전달 문구                               |
| ------------------ | --------------------------------------- |
| 전체 요약본        | `요약 노트가 아직 생성되지 않았습니다.` |
| 나의 요약본        | `요약 노트가 아직 생성되지 않았습니다.` |
| 북마크 목록        | `북마크한 요약 노트가 없습니다.`        |
| 마이페이지 북마크  | `북마크한 요약 노트가 없습니다.`        |
| 요약 상세 학습노트 | `현재 리스트가 없습니다.`               |

## 호출 계약

```jsx
<EmptyState message="현재 리스트가 없습니다." />
```

- 호출 영역은 목록 상태가 정상 완료이고 항목 수가 0일 때만 컴포넌트를 렌더링한다.
- 로딩, 오류 또는 항목이 하나 이상 있는 상태에서는 렌더링하지 않는다.
- 목록 항목과 EmptyState를 동시에 렌더링하지 않는다.
- 검색 결과 0개는 해당 목록의 최초 빈 상태와 같은 문구를 사용한다.

## 표시 계약

- `/images/clear.webp`와 안내 문구를 세로로 중앙 정렬한다.
- 안내 문구를 제외한 이미지, 간격, 색상과 타이포그래피는 모든 적용 대상에서 동일하다.
- Grid 목록에서는 전체 열을 차지하고 일반 흐름에서는 부모의 사용 가능한 너비를 사용한다.
- 장식 이미지는 보조 기술의 중복 낭독 대상에서 제외한다.
- 빈 상태는 상태 의미와 정중한 live 안내로 문구의 동적 출현을 보조 기술에 전달한다.
- 버튼, 링크, 닫기, 재시도, 생성 유도 또는 자동 이동을 표시하지 않는다.

## 호출 영역 책임

- 목록의 로딩, 오류, 정상 완료와 항목 수를 판단한다.
- 목록 문맥에 맞는 정확한 문구를 전달한다.
- 항목이 생기면 EmptyState를 제거하고 실제 목록을 표시한다.
- 실패 시 EmptyState로 대체하지 않고 해당 기능의 오류 정책을 수행한다.
- EmptyState 바깥의 제목, 검색, 버튼과 목록 배치를 유지한다.

## 책임 제외

- 데이터 조회와 검색
- 인증과 사용자 판별
- 북마크 등록·해제
- 항목 생성·수정·삭제
- 오류·로딩 표시와 재시도
- 페이지 이동과 자동 새로고침
