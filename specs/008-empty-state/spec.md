# 기능 명세: 공통 빈 상태 안내

**기능 브랜치**: `feature/empty-state`

**작성일**: 2026-08-10

**상태**: 초안

**입력**: 사용자 설명: "EmptyState 공통 표현을 전체 요약본, 나의 요약본, 북마크, 요약 상세의 학습노트 목록 및 마이페이지 북마크에 적용하고 각 상황에 지정된 안내 문구를 표시한다."

## 범위

이 기능은 목록에 표시할 항목이 없을 때 여러 페이지가 동일한 빈 상태 표현을 사용하고, 목록의 성격에 맞는 안내 문구를 제공하는 범위까지 포함한다. 목록 조회, 검색, 인증, 북마크 변경 및 항목 생성 동작은 이 기능의 범위에 포함하지 않는다.

적용 대상과 안내 문구는 다음과 같다.

| 적용 대상 | 안내 문구 |
|-----------|-----------|
| 전체 요약본 목록 | `요약 노트가 아직 생성되지 않았습니다.` |
| 나의 요약본 목록 | `요약 노트가 아직 생성되지 않았습니다.` |
| 북마크한 요약본 목록 | `북마크한 요약 노트가 없습니다.` |
| 마이페이지 북마크 섹션 | `북마크한 요약 노트가 없습니다.` |
| 요약노트 상세의 학습노트 목록 | `현재 리스트가 없습니다.` |

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 요약본 목록의 빈 상태 확인 (우선순위: P1)

사용자는 전체 요약본, 나의 요약본 또는 북마크 목록에 표시할 항목이 없을 때 현재 목록이 비어 있음을 해당 목록에 맞는 문구로 즉시 이해할 수 있다.

**우선순위 이유**: 목록이 비어 있는 상태를 오류나 로딩으로 오해하지 않게 하는 공통 안내의 핵심 흐름이다.

**독립 검증**: 각 요약본 목록에 항목이 없는 상태를 제공하고, 공통된 빈 상태 표현과 대상별 정확한 문구가 표시되는지 확인한다.

**인수 시나리오**:

1. **상황** 전체 요약본 목록의 조회 또는 검색이 정상적으로 완료됐지만 표시할 항목이 없을 때, **동작** 사용자가 목록 영역을 확인하면, **결과** `요약 노트가 아직 생성되지 않았습니다.`가 표시된다.
2. **상황** 나의 요약본 목록의 조회 또는 검색이 정상적으로 완료됐지만 표시할 항목이 없을 때, **동작** 사용자가 목록 영역을 확인하면, **결과** `요약 노트가 아직 생성되지 않았습니다.`가 표시된다.
3. **상황** 북마크한 요약본 목록의 조회 또는 검색이 정상적으로 완료됐지만 표시할 항목이 없을 때, **동작** 사용자가 목록 영역을 확인하면, **결과** `북마크한 요약 노트가 없습니다.`가 표시된다.

---

### 사용자 스토리 2 - 요약 상세의 학습노트 빈 상태 확인 (우선순위: P2)

사용자는 요약노트 상세에 연결된 학습노트가 없을 때 학습노트 목록이 비어 있음을 명확히 확인할 수 있다.

**우선순위 이유**: 요약본 자체가 없는 상황과 하위 학습노트만 없는 상황을 서로 다른 문구로 구분해야 한다.

**독립 검증**: 학습노트가 없는 요약노트 상세를 열고, 학습노트 목록 영역에 공통 빈 상태 표현과 지정 문구가 표시되는지 확인한다.

**인수 시나리오**:

1. **상황** 요약노트 상세 조회가 정상적으로 완료됐지만 연결된 학습노트가 없을 때, **동작** 사용자가 학습노트 목록 영역을 확인하면, **결과** `현재 리스트가 없습니다.`가 표시된다.
2. **상황** 요약노트 상세에 하나 이상의 학습노트가 있을 때, **동작** 사용자가 학습노트 목록 영역을 확인하면, **결과** 빈 상태 안내 대신 학습노트 항목이 표시된다.

---

### 사용자 스토리 3 - 마이페이지 북마크 빈 상태 확인 (우선순위: P3)

사용자는 마이페이지의 북마크 섹션에 표시할 요약 노트가 없을 때 북마크 기록이 없다는 안내를 확인할 수 있다.

**우선순위 이유**: 전체 북마크 목록과 마이페이지 요약 영역이 같은 의미와 문구를 제공해 사용자 혼란을 방지한다.

**독립 검증**: 북마크가 없는 사용자의 마이페이지를 열고, 북마크 섹션에 공통 빈 상태 표현과 정확한 문구가 표시되는지 확인한다.

**인수 시나리오**:

1. **상황** 마이페이지 조회가 정상적으로 완료됐지만 사용자가 북마크한 요약 노트가 없을 때, **동작** 사용자가 북마크 섹션을 확인하면, **결과** `북마크한 요약 노트가 없습니다.`가 표시된다.
2. **상황** 사용자가 하나 이상의 요약 노트를 북마크했을 때, **동작** 사용자가 마이페이지 북마크 섹션을 확인하면, **결과** 빈 상태 안내 대신 북마크한 요약 노트가 표시된다.

### 예외 상황

- 목록을 불러오는 중에는 빈 상태로 확정하지 않으며 로딩 상태를 유지한다.
- 목록 조회 또는 검색이 실패한 경우에는 빈 상태 안내로 실패를 감추지 않고 해당 기능에 정의된 오류 처리를 따른다.
- 항목이 하나라도 존재하면 빈 상태 안내를 표시하지 않는다.
- 검색 조건 때문에 결과가 0개인 경우에도 해당 목록에 지정된 동일한 빈 상태 문구를 표시한다.
- 빈 상태에서 목록 데이터가 생기면 빈 상태 안내를 제거하고 목록을 표시한다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 적용 대상 전체에서 동일한 빈 상태 표현을 사용해야 한다.
- **FR-002**: 시스템은 전체 요약본 목록에 표시할 항목이 없으면 `요약 노트가 아직 생성되지 않았습니다.`를 표시해야 한다.
- **FR-003**: 시스템은 나의 요약본 목록에 표시할 항목이 없으면 `요약 노트가 아직 생성되지 않았습니다.`를 표시해야 한다.
- **FR-004**: 시스템은 북마크한 요약본 목록에 표시할 항목이 없으면 `북마크한 요약 노트가 없습니다.`를 표시해야 한다.
- **FR-005**: 시스템은 마이페이지 북마크 섹션에 표시할 항목이 없으면 `북마크한 요약 노트가 없습니다.`를 표시해야 한다.
- **FR-006**: 시스템은 요약노트 상세의 학습노트 목록에 표시할 항목이 없으면 `현재 리스트가 없습니다.`를 표시해야 한다.
- **FR-007**: 시스템은 목록 조회 또는 검색이 정상적으로 완료되고 최종 결과가 0개인 경우에만 빈 상태 안내를 표시해야 한다.
- **FR-008**: 시스템은 목록을 불러오는 중이거나 목록 조회·검색이 실패한 상태를 빈 상태로 표시하지 않아야 한다.
- **FR-009**: 시스템은 목록에 하나 이상의 항목이 있으면 빈 상태 안내 대신 해당 항목을 표시해야 한다.
- **FR-010**: 빈 상태 문구는 표에 정의된 띄어쓰기와 마침표를 포함해 그대로 표시해야 한다.
- **FR-011**: 빈 상태 안내는 보조 기술을 사용하는 사용자도 상태 문구를 인식할 수 있어야 한다.
- **FR-012**: 빈 상태 표현 자체에는 별도로 명세되지 않은 버튼, 링크 또는 자동 이동 동작을 제공하지 않아야 한다.
- **FR-013**: 같은 빈 상태 표현을 사용하는 모든 적용 대상은 시각적 구조를 일관되게 유지하고 문구만 상황에 맞게 변경해야 한다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 다섯 가지 적용 대상의 빈 목록 검증에서 지정된 문구가 띄어쓰기와 문장부호를 포함해 100% 정확하게 표시된다.
- **SC-002**: 정상적인 목록 상태가 확정된 후 1초 이내에 목록 항목 또는 빈 상태 안내 중 정확히 하나가 사용자에게 표시된다.
- **SC-003**: 로딩, 조회 실패 또는 항목이 하나 이상 존재하는 검증 사례에서 빈 상태 안내가 잘못 표시되는 비율은 0%이다.
- **SC-004**: 모든 적용 대상의 빈 상태 화면을 비교했을 때 안내 문구를 제외한 시각적 구조가 100% 동일하다.
- **SC-005**: 보조 기술을 이용한 다섯 가지 빈 상태 검증에서 각 안내 문구를 모두 인식할 수 있다.

## 가정

- 각 페이지나 목록 영역은 조회 완료, 로딩, 실패 및 항목 존재 여부를 구분할 수 있는 상태를 제공한다.
- 공통 빈 상태의 시각 자료와 배치는 기존 프로젝트 디자인을 따른다.
- 전체 요약본, 나의 요약본 및 북마크 목록에서는 최초 목록이 비어 있는 경우와 검색 결과가 없는 경우에 같은 문구를 사용한다.
- 마이페이지 북마크는 마이페이지 내부의 요약 섹션과 전체 북마크 목록 양쪽에 같은 문구를 사용한다.
- 빈 상태에서 항목 생성이나 다른 페이지 이동을 유도하는 추가 동작은 별도 기능으로 정의한다.
