# UI 계약: Banner

## 사용 목적

`Banner`는 광고 이미지 전체를 하나의 이동 영역으로 제공하고 부모 영역의 너비에 맞춰 원본 비율로 표시한다. 광고 데이터 조회, 등록, 통계와 페이지별 크기는 책임지지 않는다.

## 컴포넌트

```text
파일: src/components/Banner.jsx
이름: Banner
스타일: src/components/Banner.module.scss
```

## 입력 계약

| 입력       | 형식   | 기본값                         | 책임                                               |
| ---------- | ------ | ------------------------------ | -------------------------------------------------- |
| `imageSrc` | 문자열 | `/images/banner.jpg`           | 표시할 이미지 경로; 명시적 빈 값이면 미표시        |
| `alt`      | 문자열 | 현재 광고를 설명하는 기본 문구 | 이미지 내용과 이동 목적 설명                       |
| `href`     | 문자열 | 없음                           | 내부·외부 목적지 판별; 없거나 미지원이면 이동 없음 |

호출자는 페이지 유형, 배너 너비·높이, 버튼 문구, 새 탭 여부를 전달하지 않는다.

## 렌더링 계약

| 조건                | 최상위 이동 요소 | 결과                         |
| ------------------- | ---------------- | ---------------------------- |
| `imageSrc` 없음     | 없음             | `null` 반환                  |
| 내부 `href`         | 내부 링크        | 현재 탭 이동                 |
| 외부 HTTP(S) `href` | 새 탭 앵커       | 외부 페이지를 새 탭에서 열기 |
| `href` 없음·미지원  | 없음             | 링크 없는 이미지 표시        |

모든 표시 상태에서 이미지 외 별도 CTA, 문구, 아이콘 또는 오버레이를 렌더링하지 않는다.

## 크기 계약

- 최상위 배너와 이미지는 부모의 사용 가능한 너비를 채운다.
- 높이는 1322×358 원본 비율에 따라 자동 계산한다.
- 이미지 전체를 표시하며 잘라내거나 비율을 강제로 변경하지 않는다.
- 페이지별 크기 유형과 고정 최대 너비를 컴포넌트 계약에 추가하지 않는다.

## 호출 영역 책임

- 실제 목적지와 광고 의미에 맞는 대체 설명을 제공한다.
- 페이지 디자인에 맞는 부모 영역 너비와 배치를 제공한다.
- 서버에서 값을 받는 경우에도 배너에는 정규화된 단순 문자열만 전달한다.
- 한 화면에 배너를 몇 개 표시할지, 어떤 광고를 선택할지는 별도 페이지 또는 광고 정책에서 결정한다.
