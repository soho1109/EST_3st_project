# 데이터 모델: 공통 광고 배너

이 기능은 데이터베이스 모델을 만들지 않는다. 아래 모델은 공통 배너가 표시할 값과 판별 상태만 정의한다.

## BannerContent

| 필드       | 형식   | 필수 여부           | 규칙                                                                  |
| ---------- | ------ | ------------------- | --------------------------------------------------------------------- |
| `imageSrc` | 문자열 | 선택                | 기본값은 `/images/banner.jpg`; 빈 값이면 배너를 표시하지 않음         |
| `alt`      | 문자열 | 이동 가능할 때 필수 | 광고 내용과 이동 목적을 설명하며 파일명만 사용하지 않음               |
| `href`     | 문자열 | 선택                | 내부 경로 또는 외부 HTTP(S) URL; 없거나 미지원 값이면 비대화형 이미지 |

## DestinationType

| 상태       | 판별 규칙                        | 렌더링 결과           | 탭 동작   |
| ---------- | -------------------------------- | --------------------- | --------- |
| `internal` | `/`로 시작하고 `//`가 아님       | 이미지 전체 내부 링크 | 현재 탭   |
| `external` | `http://` 또는 `https://`로 시작 | 이미지 전체 외부 링크 | 새 탭     |
| `none`     | 빈 값, 미지정 또는 미지원 형식   | 링크 없는 이미지      | 이동 없음 |

### 상태 전이

배너 내부에는 사용자 상태가 없다. 호출 때 받은 값에 따라 아래 결과 중 하나를 결정한다.

```text
imageSrc 없음 → 미표시
imageSrc 있음 + internal href → 내부 링크 배너
imageSrc 있음 + external href → 새 탭 외부 링크 배너
imageSrc 있음 + href 없음/미지원 → 비대화형 이미지 배너
```

## BannerPlacement

| 필드             | 소유자                  | 규칙                                |
| ---------------- | ----------------------- | ----------------------------------- |
| 사용 가능한 너비 | 호출 페이지의 부모 영역 | 페이지별 실제 배너 너비를 결정      |
| 표시 너비        | 공통 배너               | 부모 영역의 100%                    |
| 표시 높이        | 공통 배너               | 1322:358 원본 비율에 따라 자동 계산 |

`BannerPlacement`에는 `main`, `list` 같은 크기 유형이 없으며 새로운 페이지도 부모 너비만 제공한다.

## 관계와 검증

- `BannerContent`의 `href`가 `DestinationType`을 결정한다.
- `BannerPlacement`는 이미지 콘텐츠나 목적지와 무관하게 표시 크기만 결정한다.
- 목적지가 없는 상태에서는 클릭·키보드 이동 대상이 없어야 한다.
- 외부 목적지는 원래 페이지와 분리된 새 탭으로 열려야 한다.
