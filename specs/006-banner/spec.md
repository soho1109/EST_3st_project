# 기능 명세: 공통 광고 배너

**기능 브랜치**: `feature/banner`

**작성일**: 2026-08-09

**상태**: 초안

**입력**: 사용자 설명: 제공된 배너 이미지 전체를 이동 영역으로 사용하고, 메인 페이지와 학습노트 목록처럼 서로 다른 너비의 영역에서도 같은 배너를 재사용한다. 별도의 버튼은 추가하지 않는다.

- 현재 이미지 자산: `public/images/banner.jpg`

## 범위

이 기능은 하나의 광고 이미지를 공통 배너로 표시하고, 유효한 목적지가 있을 때 이미지 전체를 선택해 해당 목적지로 이동하게 하는 범위까지 포함한다. 배너 내부에 별도 버튼, 문구, 아이콘 또는 오버레이를 추가하지 않는다. 이미지 자체에 그려진 `지금 참여하기` 표현은 이미지의 일부이며 별도의 조작 요소로 취급하지 않는다.

배너의 너비는 공통 배너가 고정된 크기 유형을 갖지 않고 배치된 부모 영역을 따른다. 따라서 메인 페이지와 학습노트 목록에서 서로 다른 크기로 표시될 수 있고, 새로운 페이지에서도 별도 크기 유형 추가 없이 부모 영역의 크기로 재사용할 수 있다.

광고 콘텐츠 등록·관리, 목적지 선정, 이미지 업로드, 배너 목록·회전 노출, 통계 수집과 서버 통신은 범위에서 제외한다.

## 사용자 시나리오 및 테스트 _(필수)_

### 사용자 스토리 1 - 배너를 통한 광고 이동 (우선순위: P1)

사용자는 배너 이미지의 어느 지점을 선택해도 지정된 광고 콘텐츠로 이동할 수 있다.

**우선순위 이유**: 배너의 핵심 목적은 별도의 버튼을 찾지 않아도 광고 이미지에서 바로 관련 콘텐츠에 접근하게 하는 것이다.

**독립 검증**: 유효한 이미지와 목적지를 제공한 배너를 표시하고 이미지의 여러 지점을 선택해 모두 동일한 목적지에 도달하는지 확인한다.

**인수 시나리오**:

1. **상황** 내부 목적지가 지정된 배너가 표시되고, **동작** 사용자가 배너 이미지를 선택하면, **결과** 현재 탭에서 지정된 내부 페이지로 이동한다.
2. **상황** 외부 목적지가 지정된 배너가 표시되고, **동작** 사용자가 배너 이미지를 선택하면, **결과** 지정된 외부 페이지가 새 탭에서 열린다.
3. **상황** 이미지 안에 버튼처럼 보이는 표현이 있고, **동작** 사용자가 그 표현의 바깥쪽 이미지를 선택해도, **결과** 동일한 목적지로 이동한다.

---

### 사용자 스토리 2 - 서로 다른 페이지 너비에 맞춘 표시 (우선순위: P2)

사용자는 메인 페이지와 학습노트 목록처럼 배너 영역의 너비가 다른 화면에서도 잘리거나 왜곡되지 않은 같은 광고 이미지를 확인한다.

**우선순위 이유**: 공통 배너가 페이지별 고정 크기에 묶이지 않아야 기존 두 화면과 향후 추가 화면에서 재사용할 수 있다.

**독립 검증**: 너비가 다른 두 부모 영역에 같은 배너를 배치하고 각 영역의 너비를 채우면서 원본 비율이 유지되는지 비교한다.

**인수 시나리오**:

1. **상황** 메인 페이지의 비교적 좁은 배너 영역이 있고, **동작** 배너가 표시되면, **결과** 해당 영역의 너비에 맞춰 원본 비율로 표시된다.
2. **상황** 학습노트 목록의 더 넓은 배너 영역이 있고, **동작** 같은 배너가 표시되면, **결과** 별도 배너 유형 없이 해당 영역의 너비에 맞춰 더 크게 표시된다.
3. **상황** 새로운 페이지가 자체 너비의 배너 영역을 제공하고, **동작** 같은 배너를 배치하면, **결과** 공통 배너 변경 없이 그 영역의 너비에 맞춰 표시된다.

---

### 사용자 스토리 3 - 불완전한 배너 정보 처리 (우선순위: P3)

사용자는 이동 목적지가 없는 배너를 실수로 선택해 빈 화면이나 잘못된 위치로 이동하지 않는다.

**우선순위 이유**: 광고 목적지는 외부 콘텐츠 결정에 의존하므로 이미지와 목적지가 항상 동시에 준비된다고 보장할 수 없다.

**독립 검증**: 이미지 없음, 목적지 없음, 지원하지 않는 목적지 값을 각각 제공해 잘못된 이동이 발생하지 않는지 확인한다.

**인수 시나리오**:

1. **상황** 배너 이미지가 없고, **동작** 화면이 표시되면, **결과** 깨진 이미지나 빈 배너 영역이 표시되지 않는다.
2. **상황** 이미지는 있지만 목적지가 없고, **동작** 사용자가 이미지를 선택하면, **결과** 어떤 페이지 이동도 발생하지 않는다.
3. **상황** 지원하지 않는 형식의 목적지가 제공되고, **동작** 배너가 표시되면, **결과** 이미지는 표시될 수 있지만 이동 가능한 요소로 제공되지 않는다.

### 예외 상황

- 배너 원본과 부모 영역의 비율이 달라도 이미지를 자르거나 늘여서 왜곡하지 않는다.
- 사용자가 배너의 가장자리, 이미지 내 문구 또는 이미지 내 CTA 표현을 선택해도 클릭 가능한 배너라면 동일한 한 개의 목적지만 사용한다.
- 내부 목적지는 사이트 루트에서 시작하는 경로로, 외부 목적지는 안전한 웹 주소로 구분한다.
- 목적지가 없거나 유효하지 않으면 새 탭이나 빈 페이지를 열지 않는다.
- 한글 파일명을 사용하는 현재 이미지 자산은 이름을 임의로 변경하지 않는다.

## 요구사항 _(필수)_

### 기능 요구사항

- **FR-001**: 시스템은 광고 이미지만으로 구성된 공통 배너를 제공해야 한다.
- **FR-002**: 시스템은 배너 이미지 위나 아래에 별도 CTA 버튼, 문구, 아이콘 또는 오버레이를 추가해서는 안 된다.
- **FR-003**: 유효한 목적지가 제공되면 배너 이미지 전체가 하나의 이동 가능한 영역이어야 한다.
- **FR-004**: 내부 목적지를 선택하면 현재 탭에서 해당 내부 페이지로 이동해야 한다.
- **FR-005**: 외부 목적지를 선택하면 새 탭에서 해당 외부 페이지를 열어야 한다.
- **FR-006**: 배너는 고정된 페이지별 크기 유형을 요구하지 않고 배치된 부모 영역의 사용 가능한 너비를 따라야 한다.
- **FR-007**: 배너는 표시 너비가 달라져도 원본 이미지의 가로세로 비율을 유지하고 잘림과 왜곡 없이 전체 이미지를 표시해야 한다.
- **FR-008**: 배너를 사용하는 페이지는 자신의 레이아웃에서 배너 영역의 실제 너비를 결정해야 한다.
- **FR-009**: 이미지가 없으면 깨진 이미지나 빈 배너 컨테이너를 표시해서는 안 된다.
- **FR-010**: 목적지가 없거나 지원하지 않는 형식이면 이미지를 이동 가능한 요소로 제공해서는 안 된다.
- **FR-011**: 목적지가 없는 이미지가 표시되더라도 사용자의 선택으로 페이지 이동이나 새 탭 열기가 발생해서는 안 된다.
- **FR-012**: 이동 가능한 이미지에는 광고의 내용과 이동 목적을 이해할 수 있는 대체 설명이 제공되어야 한다.
- **FR-013**: 공통 배너의 파일명과 컴포넌트명은 프로젝트 구조에 정의된 `Banner.jsx`와 `Banner`를 사용해야 한다.
- **FR-014**: 현재 기본 배너 이미지는 `public/images/banner.jpg`를 사용하며 이 기능에서 자산명을 변경해서는 안 된다.

### 핵심 엔티티

- **광고 배너**: 화면에 표시할 이미지, 이미지 대체 설명과 선택 시 이동할 목적지로 구성된다.
- **배너 목적지**: 사이트 내부 경로 또는 외부 웹 주소이며, 내부·외부 구분에 따라 현재 탭 또는 새 탭 이동을 결정한다.
- **배너 배치 영역**: 각 페이지가 제공하는 가로 공간으로, 공통 배너의 실제 표시 너비를 결정한다.

## 성공 기준 _(필수)_

### 측정 가능한 결과

- **SC-001**: 유효한 목적지가 있는 배너의 상하좌우 및 중앙 선택 검증에서 100% 동일한 지정 목적지로 이동한다.
- **SC-002**: 내부 목적지 검증은 100% 현재 탭에서, 외부 목적지 검증은 100% 새 탭에서 열린다.
- **SC-003**: 메인 페이지, 학습노트 목록과 임의의 세 번째 너비 영역에서 배너 이미지의 잘림과 비율 왜곡이 0건이다.
- **SC-004**: 이미지가 없는 모든 검증 사례에서 깨진 이미지와 빈 배너 영역의 노출이 0건이다.
- **SC-005**: 목적지가 없거나 지원하지 않는 모든 검증 사례에서 의도하지 않은 페이지 이동과 새 탭 열기가 0건이다.
- **SC-006**: 제공 디자인과 비교했을 때 배너 외부에 추가된 CTA 버튼, 문구, 아이콘 또는 오버레이가 0건이다.
- **SC-007**: 새로운 부모 너비에 배너를 배치할 때 공통 배너에 새로운 크기 유형을 추가하지 않고 표시할 수 있다.

## 가정

- 메인 페이지와 학습노트 목록은 각자의 레이아웃에서 서로 다른 배너 영역 너비를 제공한다.
- 현재 제공된 디자인은 데스크톱 기준이며 모바일·태블릿 전용 배치는 별도 명세에서 다룬다.
- 배너 이미지와 목적지는 배너를 사용하는 영역에서 제공하며, 광고 콘텐츠를 선정하거나 저장하는 방식은 이 기능에서 결정하지 않는다.
- 사이트 내부 경로는 현재 탭에서 이동하고, 외부 웹 주소는 사용자가 현재 사이트로 돌아올 수 있도록 새 탭에서 연다.
- 현재 이미지에 포함된 `지금 참여하기` 모양은 이미지 픽셀의 일부이며 별도 버튼이 아니다.
