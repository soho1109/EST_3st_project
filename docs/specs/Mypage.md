# 마이페이지

## 목적

로그인한 사용자가 자신의 프로필 정보와 학습 노트, 직접 작성한 요약 노트, 북마크한 요약 노트를 확인하고 프로필 정보를 수정할 수 있는 페이지이다.

## URL

- 마이페이지  
  → `/mypage`

- 내 요약 노트 전체 목록  
  → `/mypage/summaries`

- 북마크 전체 목록  
  → `/mypage/bookmarks`

## 접근 조건

### 로그인 상태

- `/mypage`에 접근할 수 있다.
- 로그인한 사용자의 프로필 정보와 학습 노트, 요약 노트, 북마크 목록을 노출한다.

### 비로그인 상태

- `layout.js`에서 로그인 여부를 검사한다.
- 비로그인 상태에서의 이동 경로와 처리 방식은 미정이다.

## 화면 구성

### 프로필 영역

#### 기본 화면

- 프로필 사진
  - 등록된 프로필 사진이 없는 경우 기본 이미지를 노출한다.
- 닉네임
- 자기소개
  - 약 10~15자 내외의 한 줄 소개를 노출한다.
- `프로필 수정` 버튼

#### 프로필 수정 화면

- 프로필 사진
- 닉네임 변경 입력창
- 한 줄 소개 입력창
- `수정완료` 버튼

### 내 학습 노트 리스트

- 섹션 제목: `내 학습 노트 리스트`
- `더보기` 링크
- 학습 노트 목록

각 학습 노트 항목에는 다음 정보를 노출한다.

- 상태
- 작성자
- 학습 노트 제목
- 연관된 요약 노트의 주제
- 작성일

학습 노트는 표 형태의 목록으로 노출한다.

### 내 요약 노트

- 섹션 제목: `내 요약 노트`
- `더보기` 링크
- 요약 노트 카드 최대 4개

각 카드에는 다음 정보를 노출한다.

- 작성자 프로필 이미지
- 작성자 닉네임
- 요약 노트 제목
- 요약 노트 내용 일부
- 작성일
- 잠금 상태 아이콘

### 북마크

- 섹션 제목: `북마크`
- `더보기` 링크
- 북마크한 요약 노트 카드 최대 4개

각 카드에는 다음 정보를 노출한다.

- 작성자 프로필 이미지
- 작성자 닉네임
- 요약 노트 제목
- 요약 노트 내용 일부
- 작성일
- 북마크 아이콘
- 잠금 상태 아이콘

## 기본 상태

### 프로필 영역

- 프로필 사진, 닉네임, 자기소개를 읽기 전용으로 노출한다.
- 프로필 정보 아래에 `프로필 수정` 버튼을 노출한다.
- 등록된 프로필 사진이 없으면 기본 이미지를 노출한다.

### 내 학습 노트 리스트

- 학습 노트가 있으면 목록을 노출한다.
- 학습 노트가 없으면 다음 문구를 노출한다.

> 현재 리스트가 없습니다.
→ 모달 ?

### 내 요약 노트

- 사용자가 직접 작성한 요약 노트를 최신순으로 최대 4개 노출한다.
- 요약 노트가 없으면 다음 문구를 노출한다.

> 요약 노트가 아직 생성되지 않았습니다.

### 북마크

- 사용자가 북마크한 요약 노트를 북마크 추가가 늦은 순서대로 최대 4개 노출한다.
- 북마크한 요약 노트가 없으면 다음 문구를 노출한다.

> 북마크한 요약 노트가 없습니다.

## 사용자 행동

### 프로필 수정

1. 사용자가 `프로필 수정` 버튼을 누른다.
2. 프로필 영역이 수정 상태로 변경된다.
3. 사용자는 프로필 사진, 닉네임, 한 줄 소개를 수정할 수 있다.
4. 사용자가 `수정완료` 버튼을 누른다.
5. 수정된 프로필 정보를 저장한다.
6. 페이지 이동 없이 기본 화면으로 돌아간다.

### 프로필 사진 변경

1. 프로필 수정 상태에서 프로필 사진 위에 마우스를 올린다.
2. 프로필 사진이 어두워지면서 카메라 아이콘이 노출된다.
3. 사용자가 프로필 사진을 클릭한다.
4. 변경할 이미지를 선택한다.
5. 선택한 이미지를 프로필 사진 영역에 미리보기로 노출한다.
6. 사용자가 `수정완료` 버튼을 누르면 선택한 이미지를 저장한다.

### 닉네임 변경

1. 프로필 수정 상태에서 닉네임 입력창의 값을 변경한다.
2. 사용자가 `수정완료` 버튼을 누르면 변경된 닉네임을 저장한다.

### 한 줄 소개 변경

1. 프로필 수정 상태에서 한 줄 소개 입력창의 값을 변경한다.
2. 사용자가 `수정완료` 버튼을 누르면 변경된 한 줄 소개를 저장한다.

### 내 학습 노트 더보기

- 사용자가 `내 학습 노트 리스트`의 `더보기` 링크를 누를 수 있다.
- 이동 경로는 미정이다.
→ 학습노트 리스트 페이지로 이동

### 내 요약 노트 더보기

- 사용자가 `내 요약 노트`의 `더보기` 링크를 누르면 다음 페이지로 이동한다.

→ `/mypage/summaries`

### 북마크 더보기

- 사용자가 `북마크`의 `더보기` 링크를 누르면 다음 페이지로 이동한다.

→ `/mypage/bookmarks`

### 학습 노트 항목

- 학습 노트 항목의 클릭 가능 여부와 클릭 시 동작은 미정이다.

### 요약 노트 카드

- 요약 노트 카드의 클릭 가능 여부와 클릭 시 동작은 미정이다.

### 북마크 카드

- 북마크 카드의 클릭 가능 여부와 클릭 시 동작은 미정이다.

### 북마크 아이콘

- 북마크 아이콘 클릭 시 동작은 미정이다.

## 상태 변화

### 기본 상태에서 프로필 수정 상태로 변경

`프로필 수정` 버튼을 누르면 다음과 같이 변경된다.

- 닉네임 텍스트가 닉네임 입력창으로 변경된다.
- 자기소개 텍스트가 한 줄 소개 입력창으로 변경된다.
- `프로필 수정` 버튼이 `수정완료` 버튼으로 변경된다.
- 프로필 사진을 변경할 수 있는 상태가 된다.

### 프로필 사진 마우스 오버

- 프로필 사진 위에 마우스를 올리면 이미지가 어두워진다.
- 프로필 사진 위에 카메라 아이콘이 노출된다.

### 이미지 선택 전에서 이미지 선택 후로 변경

- 사용자가 이미지를 선택하면 선택한 이미지를 미리보기로 노출한다.
- `수정완료` 버튼을 누르기 전까지 실제 프로필 정보에는 반영되지 않는다.

### 프로필 수정 상태에서 기본 상태로 변경

- 프로필 정보 저장에 성공하면 페이지 이동 없이 기본 상태로 돌아간다.
- 변경된 프로필 사진, 닉네임, 자기소개를 노출한다.

## 서버 요청

### 마이페이지 진입 시

페이지 진입 시 다음 데이터를 조회한다.

- 로그인한 사용자의 프로필 정보
- 로그인한 사용자의 학습 노트 목록
- 로그인한 사용자가 작성한 요약 노트 목록
- 로그인한 사용자가 북마크한 요약 노트 목록

### 프로필 수정 완료 시

사용자가 `수정완료` 버튼을 누르면 다음 정보를 저장하는 서버 요청을 실행한다.

- 변경된 프로필 사진
- 변경된 닉네임
- 변경된 한 줄 소개

### 프로필 이미지 선택 시

- 이미지 선택 직후에는 선택한 이미지의 미리보기를 제공한다.
- 이미지 업로드 서버 요청이 발생하는 정확한 시점은 미정이다.

## 성공 처리

### 마이페이지 데이터 조회 성공

- 프로필 정보를 프로필 영역에 노출한다.
- 학습 노트가 있으면 목록을 노출한다.
- 직접 작성한 요약 노트를 최신순으로 최대 4개 노출한다.
- 북마크한 요약 노트를 북마크 추가가 늦은 순서대로 최대 4개 노출한다.

### 프로필 수정 성공

- 별도의 페이지 이동을 하지 않는다.
- 프로필 수정 상태를 종료한다.
- 변경된 프로필 사진, 닉네임, 자기소개를 기본 화면에 노출한다.

- 북마크 목록 조회 실패 시 처리 방식은 미정이다.

- 이미지 업로드 실패 시 처리 방식은 미정이다.

## 미정 사항

- 비로그인 사용자가 `/mypage`에 접근했을 때 이동할 경로
- `내 학습 노트 리스트`의 `더보기` 링크 이동 경로
- 마이페이지에 노출할 학습 노트의 최대 개수
- 학습 노트의 상태가 의미하는 정보
- 학습 노트 제목과 연관된 요약 노트 주제를 각각 어느 영역에 노출할지
- 학습 노트 항목의 클릭 가능 여부와 이동 경로
- 요약 노트 카드의 클릭 가능 여부와 이동 경로
- 북마크 카드의 클릭 가능 여부와 이동 경로
- 북마크 아이콘 클릭 시 북마크 해제가 가능한지 여부
- 잠금 아이콘의 의미와 클릭 가능 여부
- 내 요약 노트 정렬 기준을 작성일 기준 최신순으로 확정할지 여부
- 북마크 정렬 기준을 북마크 데이터 ID 또는 북마크 등록일 중 어떤 값으로 사용할지
- 요약 노트와 북마크 카드 내용의 최대 노출 길이와 말줄임 기준
- 프로필 이미지 서버 업로드 요청이 발생하는 정확한 시점
- 프로필 수정 취소 기능 여부
- 기존 프로필 사진을 기본 이미지로 되돌리는 기능 여부
- 프로필 수정 중 페이지를 이탈할 때의 처리 방식
- 닉네임과 한 줄 소개의 정확한 글자 수 제한
- 프로필 수정 성공 및 실패 안내 방식
- 목록 조회 실패 시 화면에 노출할 안내 문구
