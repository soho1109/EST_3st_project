## 요구사항

# 회원가입 완료 페이지

## 목적

회원가입이 정상적으로 완료되었음을 사용자에게 안내하고, 로그인 페이지로 이동할 수 있도록 제공하는 페이지이다.

## URL

- 회원가입 완료 페이지  
  → `/signup/complete`

- 로그인 페이지  
  → `/login`

- 메인 페이지  
  → `/`

## 접근 조건

- 회원가입이 정상적으로 완료된 사용자가 접근한다.
- 회원가입 완료 여부를 확인하는 방식은 미정이다.
- 세션 스토리지를 활용할 수 있는 경우, 회원가입 완료 상태 또는 직전 회원가입 정보를 임시로 저장하여 사용할 수 있다.
- 회원가입을 거치지 않고 URL로 직접 접근했을 때의 처리 방식은 미정이다.
→ 잘못된 접근입니다 모달 후 로그인 페이지로 이동 ?

## 화면 구성

### 배경

- 페이지 전체에 그라디언트 배경을 적용한다.

### 환영 문구

- 다음 문구를 노출한다.

> 프다에 오신 걸 환영해요!

### 마스코트 이미지

- 프다 마스코트 이미지를 노출한다.
- 마스코트 등장 시 크기가 작아졌다가 확대되는 애니메이션을 적용한다.
- 확대된 이후 위 아래로 통통 튀는 애니메이션을 적용한다.

### 회원가입 완료 안내

- 다음 안내 문구를 노출한다.

> 회원가입이 완료되었어요.  
> 지금부터 나만의 학습을 시작해 보세요.

### 로그인 이동 요소

- `로그인 하러 가기` 문구를 노출한다.
- 버튼 또는 링크 형태로 제공한다.
- 정확한 요소 형태는 미정이다.
   --> 로그인 하러가기 버튼 클릭 시 로그인 페이지로 이동

## 기본 상태

- 그라디언트 배경을 노출한다.
- 환영 문구를 노출한다.
- 프다 마스코트를 노출한다.
- 회원가입 완료 안내 문구를 노출한다.
- `로그인 하러 가기` 요소를 노출한다.
- 페이지 진입 시 마스코트 애니메이션을 실행한다.

## 사용자 행동

### 로그인 하러 가기

#### 로그인 페이지로 이동하는 경우

1. 사용자가 `로그인 하러 가기`를 누른다.
2. 로그인 페이지로 이동한다.

→ `/login`

#### 자동 로그인하는 경우

1. 회원가입 완료 후 로그인에 필요한 정보가 유지되어 있는지 확인한다.
2. 자동 로그인이 가능한 경우 로그인 처리를 진행한다.
3. 로그인 성공 후 메인 페이지로 이동한다.

→ `/`

- 자동 로그인 적용 여부는 미정이다.
- 로그인 정보가 없거나 자동 로그인이 불가능한 경우 로그인 페이지로 이동한다.

→ `/login`

## 상태 변화

### 페이지 진입 시

- 마스코트가 작은 크기에서 확대된다.
- 확대된 이후 위아래로 움직이는 애니메이션 상태로 변경된다.

### 로그인 이동 요소 선택 시

- 로그인 페이지 이동 방식을 사용하는 경우 `/login`으로 이동한다.
- 자동 로그인 방식을 사용하는 경우 로그인 처리 상태로 변경된다.
- 자동 로그인 성공 시 `/`로 이동한다.
- 자동 로그인 실패 시 처리 방식은 미정이다.  --> 로그인 페이지로 이동 ?

## 서버 요청

### 회원가입 완료 페이지 진입 시

- 기본 화면만 노출하는 경우 별도의 서버 요청은 발생하지 않는다.
- 회원가입 완료 여부를 서버에서 다시 확인할지 여부는 미정이다.

### 자동 로그인 적용 시

사용자가 `로그인 하러 가기`를 누르면 로그인 처리를 위한 서버 요청을 실행한다.

요청에 사용할 회원가입 정보의 보관 방식은 미정이다.

- 세션 스토리지에 임시 저장된 정보 사용
- 회원가입 직후 전달받은 정보 사용
- 별도의 인증 상태 사용

## 성공 처리

### 로그인 페이지 이동 성공

- `/login` 페이지를 노출한다.

### 자동 로그인 성공

- 로그인 상태로 변경한다.
- 메인 페이지로 이동한다.

→ `/`

## 실패 처리

### 자동 로그인 실패

- 자동 로그인 실패 시 로그인 페이지로 이동할지 여부는 미정이다.
- 실패 안내 문구와 노출 방식은 미정이다.
- 회원가입 정보 또는 입력 정보를 유지할지 여부는 미정이다.

### 회원가입 완료 상태 확인 실패

- 회원가입 완료 여부를 확인하지 못했을 때의 처리 방식은 미정이다.
- 회원가입 페이지 또는 로그인 페이지로 이동할지 여부는 미정이다.

### 직접 접근

- 회원가입을 완료하지 않은 사용자가 `/signup/complete`로 직접 접근했을 때의 처리 방식은 미정이다.
 

## 유효성 검사

- 별도의 사용자 입력 항목은 없다.
- 자동 로그인을 적용하는 경우 로그인 처리에 필요한 정보가 존재하는지 확인한다.
- 세션 스토리지를 사용하는 경우 저장된 정보의 유효 여부를 확인하는 기준은 미정이다.

## 미정 사항

- `로그인 하러 가기`를 버튼 또는 링크 중 어떤 형태로 제공할지
- `로그인 하러 가기` 선택 시 `/login`으로 이동할지, 자동 로그인 후 `/`로 이동할지
- 자동 로그인을 실제로 적용할지 여부
- 자동 로그인에 필요한 정보를 어떤 방식으로 유지할지
- 세션 스토리지 사용 여부
- 세션 스토리지에 저장할 정보의 범위
- 회원가입 완료 여부를 확인하는 방식
- 회원가입을 거치지 않고 직접 접근했을 때의 처리 방식
- 자동 로그인 실패 시 안내 문구와 이동 경로
- 마스코트 애니메이션의 반복 여부
- 마스코트 애니메이션의 실행 시간과 움직임 범위
- 마스코트 애니메이션 종료 후 최종 상태
