요구사항

## 목적

비로그인 사용자가 이메일과 비밀번호 또는 소셜 로그인을 통해 로그인하는 페이지이다.

---

## URL

`/login`

---

## 접근 조건

- 비로그인 사용자만 접근할 수 있다.
- 로그인한 사용자가 접근한 경우
  - `이미 로그인하셨습니다. 메인페이지로 이동합니다.` alert를 표시한다.
  - alert 확인 후 메인페이지(`/`)로 이동한다.

---

## 공통 구성

- Header (`header.md` 참고)
- Header 기본 상태는 접힌 상태이다.

---

## 화면 구성

### 로고 영역

- 큰 로고 이미지
  - 하단의 서비스 소개 문구를 포함한다.

### 로그인 폼

- 이메일 입력(input)
- 비밀번호 입력(input)
- 로그인 버튼
- 자동 로그인 checkbox

### 간편 로그인 영역

- 카카오 로그인 버튼
- 구글 로그인 버튼

### 회원가입 안내

- "아직 계정이 없으신가요?" 안내 문구
- 회원가입 링크

### 추가 로그인 방식

- 매직 링크 로그인
- UI 및 위치는 미정

---

## 기본 상태

- 이메일 입력값은 비어 있다.
- 비밀번호 입력값은 비어 있다.
- 자동 로그인 checkbox는 체크 해제 상태이다.
- 입력 오류 문구는 표시되지 않는다.
- 로그인 요청 중 상태가 아니다.

---

## 사용자 행동

### 이메일 입력

- 입력한 이메일을 표시한다.
- 값이 비어 있거나 이메일 형식이 올바르지 않으면 입력창 하단에 오류 문구를 표시한다.

### 비밀번호 입력

- 입력한 비밀번호를 마스킹하여 표시한다.
- 값이 비어 있으면 입력창 하단에 오류 문구를 표시한다.

### 로그인

- 로그인 버튼 클릭 시 입력값이 유효하면 Supabase에 로그인 요청을 보낸다.
- 로그인 성공 시 메인페이지(`/`)로 이동한다.
- 로그인 실패 시 오류 메시지를 표시한다.

### 자동 로그인

- checkbox를 체크하면 로그인 세션을 유지한다.
- 세션 유지 방식은 Supabase 인증 구조를 따른다.

### 카카오 로그인

- 버튼 클릭 시 Supabase OAuth를 통해 카카오 로그인 페이지로 이동한다.
- 로그인 성공 후 메인페이지(`/`)로 이동한다.

### 구글 로그인

- 버튼 클릭 시 Supabase OAuth를 통해 구글 로그인 페이지로 이동한다.
- 로그인 성공 후 메인페이지(`/`)로 이동한다.

### 회원가입

- 회원가입 링크 클릭 → `/signup`

### 매직 링크 로그인

- 사용자가 이메일을 입력하고 매직 링크를 요청한다.
- Supabase가 해당 이메일로 로그인 링크를 전송한다.
- UI 및 완료 안내 방식은 미정이다.

## 성공 처리

- 메인페이지(`/`)로 이동한다.

## 실패 처리

- 로그인 실패 메시지를 표시한다.
- 이메일 또는 비밀번호 중 어느 값이 틀렸는지는 구분하여 표시하지 않는다.

---

## 유효성 검사

### 이메일

- 필수 입력
- 이메일 형식 검사

### 비밀번호

- 필수 입력
- 비밀번호 조합 규칙은 검사하지 않는다.
- 비밀번호 생성 규칙은 회원가입 페이지에서 정의한다.
