## 요구사항

# 회원가입 페이지

## 목적

사용자가 서비스 회원가입을 진행하는 페이지이다.

---

## URL

`/signup`

---

## 접근 조건

- 비로그인 사용자만 접근할 수 있다.
- 로그인한 사용자가 접근한 경우
  - "이미 로그인하셨습니다. 메인페이지로 이동합니다." Modal 표시한다.
  - 안내 확인(또는 자동 종료) 후 메인페이지(`/`)로 이동한다.

---

## 공통 구성

- Header (`header.md` 참고)
- Header 기본 상태는 접힌 상태이다.

---

## 화면 구성

### 제목 영역

- 회원가입 제목
- 구분선(hr)

### 약관 동의 영역

- 전체 동의 checkbox
- 서비스 이용약관 동의 checkbox (필수)
- AI 생성 콘텐츠 이용 안내 동의 checkbox (필수)

### 회원 정보 입력 영역

- 닉네임 입력(input)
- 이메일 입력(input)
- 비밀번호 입력(input)
- 비밀번호 확인 입력(input)

### 가입 영역

- 가입하기 버튼 (submit)

### 로그인 안내 영역

- "이미 계정이 있습니다."
- 로그인 링크

---

## 기본 상태

- 모든 입력값은 비어 있다.
- 모든 checkbox는 체크 해제 상태이다.
- 입력 오류 문구는 표시되지 않는다.
- 회원가입 요청 중 상태가 아니다.

---

## 사용자 행동

### 약관 동의

#### 전체 동의

- checkbox를 체크하면 모든 약관을 체크한다.
- checkbox를 해제하면 모든 약관을 해제한다.

#### 개별 약관

- 개별 checkbox를 선택하거나 해제할 수 있다.
- 모든 개별 약관이 체크되면 전체 동의 checkbox도 체크 상태로 변경한다.
- 하나라도 해제되면 전체 동의 checkbox도 해제 상태로 변경한다.

### 닉네임 입력

- 입력값을 표시한다.
- 값이 비어 있으면 오류 문구를 표시한다.

### 이메일 입력

- 입력값을 표시한다.
- 이메일 형식을 검사한다.
- 값이 비어 있거나 형식이 올바르지 않으면 오류 문구를 표시한다.

### 비밀번호 입력

- 입력값을 마스킹하여 표시한다.
- 다음 조건을 만족해야 한다.
  - 영문 포함
  - 숫자 포함
  - 특수문자 포함
  - 8~10자리
- 조건을 만족하지 않으면 오류 문구를 표시한다.

### 비밀번호 확인

- 비밀번호와 일치하는지 검사한다.
- 일치하지 않으면 오류 문구를 표시한다.

### 가입하기

- 모든 필수 항목과 유효성 검사를 통과하면 회원가입 요청을 보낸다.
- 회원가입 성공 시 `/signup/complete`로 이동한다.
- 실패 시 오류 메시지를 표시한다.

### 로그인

- 로그인 링크 클릭 → `/login`

- 이메일 입력값 변경

## 유효성 검사

### 약관

- 서비스 이용약관 동의 (필수)
- AI 생성 콘텐츠 이용 안내 동의 (필수)

### 닉네임

- 필수 입력

### 이메일

- 필수 입력
- 이메일 형식 검사

### 비밀번호

- 필수 입력
- 영문, 숫자, 특수문자를 포함한 8~10자리

### 비밀번호 확인

- 필수 입력
- 비밀번호와 동일해야 한다.
