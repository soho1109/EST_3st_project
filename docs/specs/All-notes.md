# 학습노트 리스트 전체 개발 명세

## 페이지명

학습노트 리스트 전체

## 목적

내가 작성한 학습노트 목록 또는 모든 작성자의 공개 요약본 소속 학습노트 전체 목록을 조회한다.

## URL

- 내 학습노트 목록: `/mypage/summaries`
- 모든 학습노트 목록: `/allnote`

> 사용자 결정 (2026-08-14): `/allnote`는 모든 작성자의 공개 요약본 소속 학습노트를 표시한다. 잠긴 요약본 소속 노트는 전체 목록에 노출하지 않는다. `/summary/[summaryId]/notes`는 목록 페이지로 사용하지 않고 노트 생성·상세·수정 하위 경로만 유지한다.

## 접근 조건

- 로그인 여부에 따른 접근 제한 명시 없음 (미정 사항 참조)

## 공통 구성

- Header (`header.md` 참고)

## 화면 구성

- **배너 영역**: 광고 이미지 배너
- **목록 헤더**: 전체 개수 표시 (예: "27 문제") 및 테이블 컬럼 헤더 (상태, 작성자, 주제, 작성일)
- **학습노트 리스트 테이블**: 각 학습노트 아이템 항목 포함
  - 프로필 이미지 미니
  - (퀴즈풀이 여부) 상태
  - 작성자 (닉네임)
  - 주제
  - 작성일
- **Empty State**: 데이터가 없을 경우 표시되는 영역

## 기본 상태

- **`/mypage/summaries` (마이페이지 더보기)**
  - 내가 작성한 학습노트 리스트 전체를 최신순(작성일자 순)으로 표시
  - 리스트가 없을 경우: "학습 노트 리스트가 아직 생성되지 않았습니다." 메시지 표시 (`Empty State.jsx` 컴포넌트)
- **`/allnote` (모든 노트 페이지)**
  - 공개 요약본에 연결된 모든 작성자의 학습노트 전체를 최신순으로 표시
  - 잠긴 요약본 소속 노트는 표시하지 않음
  - 리스트가 없을 경우: "학습 노트 리스트가 아직 생성되지 않았습니다." 메시지 표시 (`Empty State.jsx` 컴포넌트)

## 서버 요청

- **페이지 진입 시**
  - `/mypage/summaries`: 내 학습노트 목록 조회 요청
  - `/allnote`: 공개 요약본에 연결된 모든 작성자의 학습노트 목록 조회 요청

## 성공 처리

- **`/mypage/summaries`**: 내가 작성한 학습노트 목록 데이터를 받아와 최신순으로 화면에 렌더링
- **`/allnote`**: 공개 요약본에 연결된 모든 작성자의 학습노트 목록 데이터를 받아와 최신순으로 화면에 렌더링
- **데이터가 빈 배열(0건)일 경우**: `Empty State.jsx` 화면 출력

- 비로그인 사용자가 `/mypage/summaries`에 접근할 때의 동작 및 리다이렉트 여부 (`/allnote`는 공개 목록으로 접근 허용)
- 노트 아이템 클릭 시 상세 페이지 이동 여부 및 해당 URL 경로

# 추천 사항

### UX 개선 제안

- **Empty State 내 액션 버튼 추가**: 학습노트 리스트가 없을 때 단순히 안내 문구만 보여주는 것보다, "학습노트 작성하러 가기" 또는 "요약본 보러 가기"와 같은 CTA(Call To Action) 버튼을 배치하면 사용자 참여를 유도할 수 있습니다.

### 구현 시 고려사항

- **디자인-명세 간 데이터 불일치 확인**: 전달해주신 디자인 이미지의 테이블 컬럼 헤더에는 `작성일`로 기재되어 있으나, 실제 데이터 영역에는 `80%`라는 퍼센트 값이 들어가 있습니다. 이것이 퀴즈 진행률/달성도인지, 단순 작성일 데이터 렌더링 오류인지 기획 확인이 필요합니다.
- **페이지네이션 및 무한 스크롤**: "전체 목록"을 불러올 때 학습노트의 개수가 많아질 경우를 대비해 페이지네이션(Pagination) 또는 무한 스크롤(Infinite Scroll) 적용 여부를 고려해야 합니다.

### 명세에서 결정되지 않은 사항에 대한 질문

1. 비로그인 상태로 `/mypage/summaries` 접근 시 로그인 페이지(`→ /login`)로 리다이렉트 처리해야 하는지 확인이 필요합니다.
2. 각 학습노트 아이템 클릭 시 해당 학습노트의 상세 페이지로 이동하는지, 이동한다면 경로가 어떻게 되는지 확인이 필요합니다.
