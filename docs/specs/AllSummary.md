# 학습노트 리스트 전체 개발 명세

# 목록 페이지 (전체 요약 노트 / 나의 요약 노트 / 내 북마크)

## 목적

요약 노트 목록을 조회하고, 검색을 통해 원하는 요약 노트를 찾을 수 있다.

## URL

| 페이지         | 경로                |
| -------------- | ------------------- |
| 전체 요약본    | `/summary`          |
| 나의 요약 노트 | `/mypage/summaries` |
| 내 북마크      | `/mypage/bookmarks` |

## 접근 조건

### 전체 요약본

- 누구나 접근 가능

### 나의 요약 노트

- 로그인 필요
- 비로그인 상태인 경우 처리 방식은 **미정**

### 내 북마크

- 로그인 필요
- 비로그인 상태인 경우 처리 방식은 **미정**

---

## 공통 구성

- Header (`header.md` 참고)

### 페이지 제목

- 좌측 상단에 페이지 제목 표시

페이지별 제목

- 전체 요약본
- 나의 요약 노트
- 내 북마크

### 검색 영역

- 검색 입력창(Input)
- 검색 버튼

### 목록 영역

- 카드 리스트
- 카드 Item 반복 출력

### EmptyState (`EmptyState.jsx`)

페이지별 문구

- 전체 요약본
  - "요약 노트가 아직 생성되지 않았습니다."

- 나의 요약 노트
  - "요약 노트가 아직 생성되지 않았습니다."

- 내 북마크
  - "북마크한 요약 노트가 없습니다."

---

## 화면 구성

### 카드 Item

카드에는 다음 정보를 표시한다.

- 프로필 사진
- 닉네임
- 제목
- 요약 또는 주제
- 작성일
  잠금 표시(잠긴 게시물 일 경우)
  북마크 표시 → 비로그인 시 클릭하면 공통모달(Mode = suggetLogin)

---

## 기본 상태

### 전체 요약본

- 전체 요약 노트 목록을 표시한다.

### 나의 요약 노트

- 사용자가 작성한 요약 노트 목록을 표시한다.

### 내 북마크

- 사용자가 북마크한 요약 노트 목록을 표시한다.

---

## 사용자 행동

### 전체 요약 노트 진입

다음 경로를 통해 이동할 수 있다.

- 메인 페이지의 **전체 요약 노트 바로가기 카드** 클릭
- Header Navigation의 **전체 요약 노트** 메뉴 클릭

→ `/summary`

---

### 검색 입력

- 검색어를 입력한다.

---

### 검색 버튼 클릭

- 입력한 검색어로 목록을 검색한다.

> 검색 동작 방식은 아래 두 가지 중 하나로 결정되어야 한다.
>
> - Input `onChange` 시 즉시 필터링
> - 검색 버튼 클릭(제출) 시 필터링

---

### 카드 클릭

- 선택한 카드의 상세 요약 노트 페이지로 이동한다.

→ `/summary/[summaryId]`

---

### 스크롤

- 목록 하단까지 스크롤하면 다음 목록을 불러온다.

(무한 스크롤)

- 텐스택쿼리라는걸 추천하심

---

## 상태 변화

### 검색 결과 존재

- 검색 결과 목록을 표시한다.

### 검색 결과 없음

- EmptyState를 표시한다.

### 데이터 없음

페이지별 EmptyState를 표시한다.

---

## 서버 요청

### 페이지 진입

목록 데이터를 조회한다.

### 검색

검색 조건에 맞는 목록을 조회한다.

### 무한 스크롤

다음 목록 데이터를 조회한다.

---

## 성공 처리

### 목록 조회 성공

- 카드 목록을 표시한다.

### 검색 성공

- 검색 결과를 표시한다.

### 무한 스크롤 성공

- 기존 목록 하단에 데이터를 추가한다.

---

## 실패 처리

- 목록 조회 실패 처리 방식은 **미정**
- 검색 실패 처리 방식은 **미정**
- 무한 스크롤 실패 처리 방식은 **미정**

---

## 유효성 검사

- 검색어 유효성 검사 방식은 **미정**

---

## 미정 사항

- 검색 방식
  - Input `onChange` 즉시 검색
  - 검색 버튼 클릭 후 검색
  - 위 두 방식 중 하나로 결정 필요

- 비로그인 상태에서 `/mypage/summaries` 접근 처리 방식

- 비로그인 상태에서 `/mypage/bookmarks` 접근 처리 방식

- 무한 스크롤 구현 방식
  - `loading.js` 사용 여부
  - 추가 데이터 로딩 UI
  - 마지막 페이지 도달 처리

- 목록 조회 실패 시 사용자에게 표시할 UI 또는 메시지

- 검색 실패 시 사용자에게 표시할 UI 또는 메시지
